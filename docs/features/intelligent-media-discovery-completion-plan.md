## P1 具体设计

1. **身份唯一 owner 为 face**：指纹覆盖 face-v1、buffalo_l、512 维、运行时/缓存摘要、预处理与质量规则摘要、detector/embedder hash、阈值 profile。阈值必须经现有 ParseThresholdProfile 验证；摘要匹配只证明兼容，来源和质量仍须有证据。
2. **复用事务**：service 模型 content_hash/source_identity 存完整指纹，FaceGeneration.model_id 绑定该模型；事务中复核组件/阈值及 operation kind/state/revision/availability，再退役旧代次、插入新代次、完成操作。保持各库旧可见聚类和 CLIP 活动指针不变，不建立另一套任务状态机。
3. **激活适配**：app 通过独立预期身份校验 FaceClient，返回 Metadata，并向 face 身份绑定仓储入口提交；禁止服务响应自行成为信任基准，禁止旧文件入口激活 service。
4. **配置/恢复**：在已有部署配置范围内加入可选人脸配置；省略人脸配置时不启用，显式配置缺少/无效 profile 时拒绝启动并报告配置错误，不静默降级。运行期 AI 离线不阻塞核心浏览。模型不可用与本地并发忙分开；重试复用现有有界、持久化语义。
5. **主进程组合**：安全媒体源 → imagevips → FaceRuntime → face.Processor → JobProcessor → SQLite；共享资源控制、单 worker、既有队列与关闭顺序。验证运行前后代次一致，旧代次任务不得写新代次。
