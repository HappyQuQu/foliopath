# FolioPath 术语表

本文统一产品、界面、API 和代码中的核心用词。新增同义词前应优先复用这里的术语，避免把 Docker 挂载、媒体库和普通目录混为一谈。

| 术语 | 含义 |
| --- | --- |
| 允许媒体根目录（allowed media root） | 容器内固定且唯一的 `/library` 媒体挂载。它是 FolioPath 能选择和读取媒体的最大边界，不等同于一个具体媒体库；其后代必须是普通目录，不能是嵌套挂载。 |
| 数据目录（data root） | 容器内固定的 `/app/data`，保存配置、SQLite、任务状态和可重建缓存。不能作为媒体库。 |
| 媒体库（library） | 用户在 Web 设置中创建的命名浏览范围，指向 `/library` 本身或其一个子目录，默认包含所有后代目录。 |
| 媒体库根目录（library root） | 某个媒体库对应的目录。数据库保存它相对于 `/library` 的规范化路径。 |
| 目录（directory） | 媒体库内保留原始层级的文件夹。产品界面统一称“文件夹”时，API 和代码仍可使用 directory。 |
| 当前目录浏览（direct view） | 只显示当前目录直接包含的媒体，不包含子目录中的媒体。 |
| 递归浏览（recursive view） | 显示当前目录及所有后代目录中的媒体，并保留每项的来源相对路径。它是浏览方式，不创建相册或复制文件。 |
| 媒体 / 媒体项（asset） | 被索引的一张图片、动画图片或一个视频。目录本身不是媒体项。 |
| 原始媒体（original） | `/library` 中用户已有的源文件。FolioPath 将其视为只读，不移动、改名、修改或删除。 |
| 派生数据（derived data） | 可以从原始媒体重建的索引、元数据、缩略图、视频封面和搜索索引。 |
| 缩略图（thumbnail） | 为列表或网格生成的小尺寸图片派生文件。 |
| 视频封面（poster） | 从视频提取、用于尚未播放时展示的静态画面。 |
| 完整扫描（full scan） | 流式遍历一个媒体库全部可访问目录并在成功后校准陈旧记录的过程。 |
| 增量扫描（incremental scan） | 只检查已知变化范围的过程；它不能执行媒体库级陈旧记录清理。 |
| 扫描代次（generation） | 标记一次完整扫描发现结果的单调值。只有成功代次有资格清理更早记录。 |
| 离线（offline） | 媒体库根目录不存在或不可读，常见于挂载暂时断开。已有索引必须保留。 |
| 扫描错误（scan error） | 根目录存在，但完整遍历、读取或写入没有可靠完成。该次扫描不能清理旧索引。 |
| 源指纹（source fingerprint） | 至少由文件大小和高精度修改时间构成的变化标识，用于使过期元数据与缩略图失效；不是内容去重哈希。 |
| 重叠媒体库（overlapping libraries） | 两个媒体库根目录相同，或一个是另一个的祖先目录。MVP 默认拒绝这种配置。 |
| 相对路径（relative path） | 相对于 `/library` 或某个媒体库根目录的路径。公开界面与 API 不暴露宿主机绝对路径。 |
| MVP | 首个可用版本的计划范围。出现在文档中不代表对应能力已经发布。 |

## 路径示例

给定 Docker 映射：

```text
宿主机 /mnt/photos  →  容器 /library
```

用户创建媒体库“家庭照片”，选择 `/library/family`：

```text
允许媒体根目录     /library
媒体库根目录       /library/family
数据库根路径       family
一个媒体相对路径   2026/Shanghai/IMG_0001.jpg
真实容器路径       /library/family/2026/Shanghai/IMG_0001.jpg
```

API 使用媒体库 ID、目录 ID 和媒体 ID；最后一行的真实路径只允许由服务端文件边界代码解析。
