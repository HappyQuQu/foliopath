1. 解析后恰好两个服务，AI 内部网络无端口/媒体/数据库卷，主应用不依赖 AI 健康。
2. 只启动主应用即 healthy；未认证媒体库 API 返回 401，初始化管理员、登录及鉴权读取成功。
