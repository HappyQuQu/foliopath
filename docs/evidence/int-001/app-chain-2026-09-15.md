# 本地主进程图片/视频链路（2026-09-15）

范围：CR-2026-030 / POST-MVP-5 / FR-INT-001/002/005/006/007/017/020。
Owner api/app；沿用 OpenAPI、原 worker、semantic 及 SQLite 合同。

## 发现与修复

1. 开启语义分析首次返回 404：OpenAPI/生成客户端使用 PATCH，后端却只注册 PUT。
   修正后端为合同定义的 PATCH，并修改设置/非法输入 HTTP 回归使用 PATCH。
2. 回归镜像没有 FFmpeg，无法作为视频端到端运行环境。候选 Compose 改用根
   Dockerfile 实际 distroless 运行镜像，保留私网 AI、回环主端口、只读媒体。
3. 原 range-video.mp4 仅 1 秒，按 2 秒门槛不生成故事板。新增临时合成 3 秒
   H.264 夹具生成脚本；不修改规则，不用真实媒体。1 秒视频明确保留为降级样例。
4. 改换合成文件根时，图片源指纹改变，旧幂等 key 重放已完成任务；出现 coverage
   complete=true 但搜索返回空。新 missing 作业完成后恢复。覆盖率与实时指纹变化
   的一致性仍需专门修复/回归，不能因重新回填恢复就标该问题已解决。

## 成功结果

- 主进程认证 API 建库并扫描 3 个合成文件（最初两项，后增加视频）。
- 图片回填 completed=1 / eligible=1，failed=0，complete=true，文本 q=blue 返回图片。
- 3 秒视频经实际 FFmpeg 生成 4 帧故事板，真实离线 AI 回填后搜索返回视频，
  匹配帧 ordinal=2、timestampMs=1800、planSize=4。
- 视频 coverage eligible=2 / completed=1 / degraded=1 / failed=0 / complete=false：
  1 秒夹具降级且不进入搜索，不能将该结果写为所有视频完成。
- 重启主容器后再次运行同一脚本，图片和视频搜索均 PASS，活动代次保持。
- 只验证链路，不代表检索相关性、中文质量、人脸、UI 或发行验收。
