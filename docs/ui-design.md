# FolioPath 界面设计规格

## 文档状态与方向

本文是首个可用版本的已确认 UI 行为基线。用户已于 2026-07-23 确认 RQ-001～RQ-014
全部采用 A，并于 2026-07-29 确认
[Apple 风格静态原型](../prototypes/apple-redesign/index.html)的视觉方向、浅色/深色、自适应和
[非模态预览规则](changes/CR-2026-001-non-modal-media-preview.md)。生产实现仍必须遵循后端优先
Gate；原型不进入生产 import graph。源码分层、设计系统唯一所有权、API/状态和禁止重复实现规则
见[前端子系统架构](architecture/frontend.md)。

生产还原由正式 feature [FTR-UIF-001](features/frontend-prototype-fidelity.md)承接；范围、
后端合同、视觉 Gate 与执行顺序以其
[开发清单](features/frontend-prototype-fidelity-task-list.md)为准。当前生产页面、共享壳和
真实合同消费已完成 `UIF-401～408` 并通过
[`UIF-S4 Integrated Slice Done`](gates/MVP-2026-07-23/uif-s4-integrated-slice-done.md)；
逐页原型比较、Linux 基线、四档逐页审阅、浏览器/可访问性和容量证据统一汇总在
[当前 UIF 集成状态](releases/MVP-2026-07-23-uif-integration-status.md)。该状态不等于稳定发布。

设计方向是“内容优先、目录清晰、状态诚实”：采用克制的 Apple 桌面应用视觉语言，以系统字体、
半透明层级、紧凑工具栏、圆润表面和轻量动效组织信息，让照片和视频成为主要色彩；文件夹层级
始终可定位；扫描、离线和错误状态不伪装成空内容。FolioPath 仍是跨平台 Web 应用，视觉参照不
改变 Web 语义、键盘操作和浏览器兼容要求。

## 信息架构

应用顶层分为三个任务：

```text
FolioPath
├── 全局 Header
│   ├── 全局搜索
│   ├── 语言 / 主题快捷切换
│   └── 管理员菜单
├── 浏览
│   ├── 媒体库切换
│   ├── 目录树 / 面包屑
│   ├── 当前目录 / 包含子目录
│   └── 网格 / 瀑布流 / 查看器
├── 搜索
│   ├── 查询与筛选
│   └── 结果 / 查看器
└── 管理中心
    ├── 配置（通用 / 扫描 / 缓存）
    ├── 媒体库（媒体库 / 扫描记录 / 处理结果）
    ├── 账户
    ├── 系统日志
    └── 关于
```

**目标路由：**

- `/libraries/:libraryId/browse/:directoryId`
- `/libraries/:libraryId/search?q=…` 与跨媒体库 `/search?q=…`，不使用虚假的媒体库 ID
- `/libraries/:libraryId/media/:mediaId`（保留来源列表上下文的叠层路由）
- `/settings/libraries`、`/settings/libraries/new` 与
  `/settings/libraries/:libraryId/status`

库、目录、搜索、递归模式、排序、筛选和分页游标或可恢复锚点进入 URL；不写入宿主机或容器绝对路径。具体路由字段在 OpenAPI 和前端路由评审时确定。

## 应用壳与响应式布局

| 视口 | 已确认布局 | 导航行为 |
| --- | --- | --- |
| `< 640px` | 单列；48–56px 顶栏；内容全宽 | 库和目录在独立全屏面板或底部面板中选择；工具栏允许换行 |
| `640–1023px` | 可覆盖的目录侧栏；主内容保持全宽 | 侧栏由明确按钮打开，选择目录后自动收起 |
| `≥ 1024px` | 全局 Header + 固定目录侧栏 + 自适应主内容 | Header 的左右区域等宽伸缩，使全局搜索始终保持视觉居中；目录侧栏只承载媒体库切换器和目录树 |

所有认证后的主页面共用一条横跨完整视口的全局 Header：左侧是 FolioPath 入口，中间是
可直接提交并进入结果页的全局搜索，右侧依次是快速语言切换、快速主题切换、消息中心和管理员菜单。
语言按钮复用通用设置中的语言状态与持久化规则，在简体中文和英文间即时切换；主题按钮复用
通用设置中的主题状态与持久化规则。两个按钮都通过图标和随当前状态变化的无障碍标签说明
下一步操作。
管理员菜单只提供“管理中心”和
“退出登录”入口；进入管理中心后再由其分类导航切换具体模块，避免与 Header 重复。浏览目录侧栏不再重复显示搜索、媒体库或设置。管理中心在 Header 下方使用
可在 216–280px 间自适应的单层左侧导航，内容区占满剩余宽度；配置、媒体库、账户、系统日志和关于
使用一致的图标、行高和选中状态，不再插入额外分组标题，
`≤ 720px` 时折叠为横向分类条。五个分类分别使用
`/settings/general`、`/settings/libraries`、`/settings/account`、
`/settings/logs` 和 `/settings/about`
独立路由；页面刷新、浏览器前进后退和复制地址必须保留当前分类，不能再用同页锚点模拟页面。
配置内部的通用/扫描/缓存和媒体库内部的媒体库/扫描记录/处理结果使用 URL
查询参数保留页签；`/settings/storage` 仅保留旧深链兼容，不再出现在主导航。
媒体库列表页在保留响应式安全边距的前提下占满管理主区域，不使用设置表单的固定内容宽度；
卡片内名称与路径弹性伸缩，操作组在空间不足时换行。

桌面主内容顶部依次为面包屑和浏览工具栏；浏览工具栏提供“刷新当前目录”，
搜索命令区提供“刷新搜索结果”。两者保持当前 URL/筛选/排序，丢弃后续 cursor 页并从
第一页重取。返回浏览优先保持来源媒体库，全局页面返回默认浏览入口。用户菜单直接提供退出登录，支持
点击外部或 `Escape` 关闭并恢复触发器焦点。浏览页“全部 / 图片 / 视频”媒体类型三态直接显示
在工具栏左侧；漏斗只用于后续高级筛选，不再作为孤立的媒体类型入口。刷新使用工具栏末端的紧凑
图标，不新增第二套视觉样式。默认入口直接打开可浏览的媒体库。滚动容器只保留
一个，避免侧栏、页面和媒体网格争夺滚轮。移动端不永久占用底部导航栏；查看器和目录面板
始终提供可见关闭按钮，不能只依赖手势。
从库内浏览或搜索进入通用设置时，路由必须保留当前 `libraryId` 上下文。

生产还原的执行顺序、逐页路由/合同映射、同视口比较矩阵和 Definition of Done 见
[生产前端与原型一致性改造方案](frontend-prototype-fidelity-plan.md)。原型是视觉真相，
OpenAPI 与 Backend Ready 是功能真相；任何一方都不能静默覆盖另一方。

当前审计口径将两类证据分开：12 个 manifest 页面在共同 `1280 × 720` CSS 视口完成逐页
原型/生产组合比较；`390×844 / 768×1024 / 1265×800 / 1440×900` 由双语双主题状态矩阵、
页面 overflow、输入和响应式测试覆盖。文档不得把前者误写成四档逐页截图，也不得用后者
替代每页功能纵向链。

## 主要页面

### 欢迎与首次设置

- 未初始化实例先显示单管理员创建页，不提供默认密码；初始化后使用登录页。会话过期保留安全返回位置并要求重新登录。
- 创建页依次收集显示名称、用户名、密码和确认密码；登录页只收集用户名与密码。首次密码
  至少 8 个 Unicode 字符，不强制大小写、数字或特殊字符组合；必填、长度和密码一致性错误
  紧邻对应字段，凭据失败使用统一文案，不泄露账号是否存在。
- 用一段话说明只读媒体、`/library` 挂载和 Web 内创建媒体库的关系。
- 主操作只有“创建媒体库”；Docker 帮助作为次级链接。
- 初始化错误使用阻断卡片、稳定错误码和重试，不展示技术堆栈。

### 浏览页

- FolioPath 的核心交互是单一媒体工作台：左侧选择目录、全部媒体、收藏或标签，中间展示当前
  集合，右侧展示并整理当前媒体。切换集合只更新工作台上下文和 URL，不进入一套独立的
  “收藏管理页”或“标签管理页”。媒体库切换器和快速访问始终保留在同一左栏；全部媒体与收藏
  视角保留完整目录树；收藏视角隐藏目录树，只在快速访问项旁显示收藏总数；标签视角隐藏
  目录树，把余下侧栏作为标签墙使用。媒体类型与排序筛选只保留在中间工具栏，不在侧栏重复。
- 标签墙展示标签名称和媒体数量，并按数量映射到 5 个受控字号等级；数量越多字号越大，
  但数量徽标始终可见，不能只靠字号传递数量。点击标签只更新中间集合和 URL。
- 侧栏顶部是媒体库切换器和状态；其下是可折叠目录树。
- 媒体库切换器使用双行触发器呈现当前库名称、状态与媒体数量；展开为锚定在触发器下方的
  轻量列表浮层。当前库同时使用浅色选中底、勾选图标和 `aria-selected` 表达，不只依赖颜色。
  浮层支持方向键、Home/End、Escape、焦点恢复和点击外部关闭。
- 图标按钮、图标加文字按钮、目录行和复选框行使用显式的居中布局；图标不参与文本基线计算，
  图标与单行文字至少保留 8px 间距，目录行采用 12px。原生复选框清除浏览器默认外边距，
  多行说明场景按整行视觉中心对齐。
- “全部媒体”是显式进入当前媒体库递归范围的快捷入口；媒体库根节点表示当前选中的
  根目录。用户在根目录用“包含子目录”切换范围时，根目录仍是当前项，不能把侧栏当前项
  偷换成“全部媒体”。显式的全部媒体入口使用可恢复的 URL 状态与根目录递归区分。
  范围开关与布局切换组成一个紧凑控制组，不制造相互竞争的表面。
- 主区顶部显示可横向滚动或折叠的面包屑，避免深层路径挤掉操作。
- 工具栏左侧集中放置“包含子目录”和媒体类型，右侧依次放置当前目录关键字、布局与排序，
  让范围选择和结果操作形成两组清晰层级。关键字按当前目录中的子目录名和媒体文件名过滤，
  并写入 URL；它不是全局搜索。媒体类型以
  “全部、图片、视频”三态直接可见，其中“图片”同时筛选静态图片与 GIF 动图；高级筛选进入弹层。
- 当前目录模式先显示直接子目录，再显示媒体；递归模式重点显示媒体，并在卡片上展示来源路径。
- 扫描横幅占用固定小区域，不用反复出现 toast 干扰浏览。

### 搜索页

- 搜索输入保持可见；查询、范围、类型和日期筛选紧邻结果。
- 结果沿用媒体卡片，但文件名和相对路径必须可见或可访问，不依赖悬停。
- 空结果、请求失败和媒体库离线是三个不同状态。
- 生产路由使用 `/libraries/:libraryId/search` 表达库内上下文，使用 `/search` 表达全部库；
  唯一 URL codec 保存 `q`、`scope`、`directoryId`、`recursive`、`kind`、`date`、
  `sort` 和 `order`，复制、刷新与浏览器前进/后退必须恢复同一查询。
- 搜索输入由共享 `SearchInput` 所有，结果复用共享 `MediaCollection`；搜索 feature 只组合
  契约范围、筛选、query 和来源信息，不复制卡片、虚拟化、布局偏好或后续非模态预览。
- 服务端未提供总数时只显示“已载入”数量，不推算总量；全部库结果显示库名和
  library-relative 来源，库内结果仍提供可访问来源目录链接。
- 搜索结果复用浏览页的唯一非模态预览 controller 和 `MediaPreview`。固定后继续编辑查询
  或筛选不得中断图片/视频；当前媒体不再属于结果集时保留预览并显示明确状态，前后项暂时
  禁用。媒体重新出现后恢复结果位置，关闭仍恢复对应虚拟卡片焦点。
- 通用设置统一拥有新打开浏览/搜索的默认排序与网格/瀑布流布局。排序缺省仍可选择“按
  当前视图默认”（直接目录名称正序、递归/搜索修改时间倒序），也可固定六种字段/方向组合；
  URL 中显式 `sort/order` 优先，偏好产生的非契约默认必须规范化写回 URL。

### 媒体查看器

- 目录、收藏、标签与搜索默认先打开同一个非模态预览。桌面预览停靠在主内容右侧并允许调整宽度；父列表保持可见、
  可滚动和可操作。窄屏预览进入内容流，不使用阻断父页面的遮罩。
- 桌面目录栏与预览栏复用同一可见分隔条交互：鼠标或指针拖动边缘调整宽度，方向键按
  24px 步进，Home/End 跳到边界。两个宽度偏好分别记忆；移动抽屉和窄屏入流预览隐藏分隔条。
- 未固定时单击其他媒体立即切换预览；固定后单击只改变列表选择，双击才切换预览。视频在固定
  预览期间继续播放；界面必须同时清楚表达“当前选择”和“当前预览”。
- 通用设置提供默认开启的“自动播放视频预览”。开启时新挂载的非模态视频以静音方式自动
  播放并保留原生控件；关闭时不请求自动播放。该偏好不作用于完整查看器或故事板 hover。
- 固定状态、选择/预览分离、媒体快照、宽度、Escape 和虚拟焦点恢复由跨目录/收藏/标签/搜索共享的
  controller 唯一拥有；feature 只能提供当前结果与业务文案，不能复制状态机。
- 预览栏的上一项、位置、下一项和完整查看器操作不得拆分按钮文案；宽度不足时完整查看器
  单独换行，详情列表从顶部紧凑排列，不用剩余高度拉散字段。
- 完整查看器由预览中的显式操作进入并保留可直达路由。它使用近黑背景突出媒体；顶部工具栏包含
  关闭、文件名、信息和必要操作，左右切换按钮在指针设备上可见；不使用常驻底部状态栏。
- 信息面板默认收起；桌面端从右侧出现，移动端使用全高或底部面板；面板不遮住关闭出口。
- 查看器根容器接收路由初始焦点且不产生多余视觉描边，关闭按钮保持为首个 Tab 停靠点；
  键盘用户仍可直接使用 `Esc`、左右方向键和 `i`。
- 查看器支持适应视口、缩放/平移、1:1、前后切换和全屏；chrome 可在安静浏览时淡出，但键盘操作、指针移动或聚焦后立即恢复。
- 信息区只提供文件名、相对路径、类型、尺寸或时长和修改时间；MVP 不提供完整 EXIF 面板、显式下载按钮或移动端滑动手势。
- 浏览器实际播放失败的视频、原文件离线和损坏媒体保留同一查看器框架，显示可理解的替代状态。
- 媒体状态判断只有一个 owner：source offline/missing/unreadable 优先于 probe
  failed/unsupported。服务端派生的 `unsupported_codec` 不得在创建原生播放器前阻断视频；
  浏览器触发媒体 error 后才显示播放失败。状态替换媒体内容但保留关闭、前后项与可靠索引
  信息；可恢复状态提供重新检查，已删除不显示无效重试。
- GIF 直接使用认证原内容保持动画；视频使用原生 controls、playsInline、metadata preload
  和 ready thumbnail poster。MVP 不转码。移动端初始收起基本信息，避免底部面板遮挡状态
  主操作，用户仍可从同一信息按钮打开。

### 媒体库设置

- 列表行显示名称、相对根目录、状态、最近成功扫描时间和安全错误摘要。
- 名称必填且实例内唯一；“新建媒体库”是页面主操作。重新扫描、取消扫描、重试和编辑名称为普通操作；根路径不可原地修改，“从 FolioPath 移除”单独放入危险区。
- 路径选择器使用面包屑 + 单层目录列表。冲突、不可读和符号链接目录显示禁用原因，不让用户提交后才发现所有问题。
- 设置同时提供默认 24 小时完整扫描周期、10 GiB 缩略图缓存配额和简体中文/英文切换；扫描周期与缓存配额可修改。
- 语言默认跟随浏览器首选语言，并允许在通用设置中切换和持久化覆盖；切换后当前界面、
  可访问名称和 `html[lang]` 同步更新，不要求重新载入。全局 Header 的语言图标提供
  简体中文/英文快速切换，并与通用设置中的当前语言字段保持同步。
- 全局 Header 右上角账户菜单使用“管理中心 / Management Center”进入管理页面，不使用范围
  含糊的“设置 / Settings”；目标路由和当前媒体库上下文保持不变。
- 改名使用带当前名称的确认对话框；移除确认逐项说明只清理 FolioPath 配置、索引、任务和
  可重建缓存，并持续强调原始目录与媒体不会被删除、移动或修改。
- 扫描详情默认在媒体库行下方展开，旧的独立可直达状态页仅保留深链兼容；详情展示阶段、
  可确定或不确定进度、目录/媒体/问题计数、起止时间和脱敏问题摘要。失败、离线、中断或取消后
  必须明确最后可靠索引仍被保留。
- 扫描详情内容随管理中心剩余宽度伸缩，宽屏使用更多空间展示进度与计数；窄屏将摘要、计数和
  操作自然换行，不出现固定 52rem 内容列或页面级横向滚动。
- 媒体库列表的“查看状态”在被点击行正下方展开行内详情，在不离开列表、不使用遮罩、不丢失
  滚动位置的前提下展示完整的最近扫描和派生媒体实时进度；不再提供二次跳转到完整状态页的
  入口，行内展开区就是该操作的完整查看界面。未展开行只保留浏览和配置管理操作；补齐失败
  项目、完整扫描与进行中扫描的取消操作统一放在展开详情底部，避免重复按钮。
- 媒体库行同时显示自动发现的文字状态；降级或不支持状态通过辅助说明提供净化原因和最近自动
  同步时间，不只依赖颜色。列表标题区提供明确刷新按钮。媒体库、浏览或搜索页面可见时以 5 秒
  ETag 条件检查检测 content revision；`304` 不改变页面，revision 变化只重建当前 active
  scope 第一页，页面隐藏时停止检查。
- 同一状态页在扫描进度下分开展示缩略图/视频封面与视频悬停预览的后台生成计数；扫描完成后
  派生任务仍活动时继续刷新。扫描仍发现媒体或视频预览资格尚未稳定时使用不确定进度，失败数
  必须单列，不能用 100% 掩盖失败。
- 配置的通用页签将主题、语言和已批准的浏览偏好放在独立保存事务中；扫描和缓存页签将扫描开关/周期
  与缓存配额分别保存。账户页提供显示名称、密码和当前会话操作。所有页面在有修改时显示
  脏状态；并发修改与契约校验失败保留用户输入并给出可恢复提示。
- 独立管理页不是静态展示：媒体库页签覆盖创建、名称校验、服务端批准目录选择、扫描/取消/
  重试、改名和安全移除；扫描记录与处理结果页签承载任务历史与失败排查；配置页签覆盖计划校验、
  配额和可重建缓存清理；账户页覆盖显示名称、密码规则、确认密码和退出登录确认。
- 生产管理壳使用唯一 `GlobalHeader` 与 `ManagementShell`：Header 左侧为正式品牌、中央为
  全局搜索、右侧为语言/主题快捷切换和账户菜单；桌面管理导航保持 216～280px，内容占满剩余宽度。390px 档
  分类导航自然换行而不制造页面级横向滚动，品牌字标可隐藏但目录树图形必须保留。
- 通用页的布尔偏好使用共享 `Switch`，不得在页面内复制开关 CSS。其保存条只在页面内容
  中表达本页脏状态，不复制 Header 或导航。首轮 1440×900 与 390 档证据见
  [`design-qa.md`](../design-qa.md) 和 `docs/evidence/uif-301/`。
- 筛选、排序和设置中的下拉框复用共享 `Select`：保留 native select 语义和键盘行为，
  统一高度、箭头、圆角、hover、focus-visible、disabled 与 invalid 状态；筛选组宽屏等分、
  窄屏单列，不退回浏览器默认黑边样式。

### 后台任务与系统维护原型

- 生产 Header 的消息中心使用扫描、派生失败和 release-info 的只读投影；进行中、需处理与
  最近完成均可直达真实页面。“清除已完成”只保存当前浏览器的通知确认，不删除任务或日志。
  版本提醒显示检查时间，失败显示最近失败时间，扫描完成显示完成时间；活动项只显示可靠的
  实时状态和进度，不用当前时间伪装任务开始时间。
- 媒体失败是一个聚合事件，角标只加 1，不使用当前页最多 50 条记录直接填充角标。用户进入
  处理结果或点“已知晓”后保存服务端最新失败修订号（完成时间 + job ID）；新增失败或同一 job
  重试后再次失败都会产生不同修订号并重新提醒。活动任务
  没有确认或隐藏入口。
- 活动派生任务在消息项内显示进度条，以及已处理/总数、排队、处理中、失败计数；活动期间
  以 1.5 秒间隔刷新，点击后进入对应媒体库状态页。
- 媒体库“处理结果”分页显示既有 `media_jobs` 终态失败，包含 library-relative path、
  variant、稳定错误码、尝试次数和用户建议；“查看原因”在原记录内展开最近 10 次尝试，
  不弹框、不跳页，并展示阶段、具体稳定原因、工具、退出码和耗时。失败通知直达该页签。“扫描记录”按时间
  倒序组合各媒体库已有 `scan_runs` 历史。源文件超限显示 `source_too_large`，不得显示成损坏；
  `missing_moov_atom` 显示“MP4 索引缺失或文件未完整复制”。视频信息已识别但 poster 失败时，
  媒体仍可打开并交给浏览器尝试播放，卡片只回退无封面状态。
- “清除当前结果”仅在当前浏览器保存全局失败修订水位并隐藏此前结果；新失败仍显示。
  “恢复已清除结果”可重新展示服务端保留的诊断。两者都不删除任务、attempt、缓存或原媒体。
- “系统日志”展示日常应用事件，按错误/警告/信息和模块筛选；详情只展开稳定事件码、
  request ID、route pattern、状态码与耗时，不显示 host path、SQL、stack、请求内容或原始 stderr。
- 关于页显示构建注入版本、API 版本、稳定 Release 历史和更新状态；每版卡片在日期下直接按
  标题、项目列表和段落展示更新正文，不显示外部 Release/commit 链接；更新检查失败不影响
  readiness，也不在应用内操作容器。

- 后续媒体库任务中心把每库完整扫描、缺失缩略图、视频封面和缓存水位清理统一为可
  直达任务；列表提供进行中、全部、需处理筛选，但不复制各 capability 的任务状态机。
- 每个任务详情展示文字状态、阶段、进度或未知总量、已处理数量、更新时间、取消或重试。
  “补齐缺失”是默认低成本操作，包含未生成、缓存丢失及全部失败结果；“全部重建”使用四字
  按钮并明确成本、二次确认。文件树“重新扫描”保持独立，不冒充派生媒体的全部处理。
- 失败、离线、取消和中断记录持续保留，明确说明最后可靠索引或已安全生成的派生文件仍保留；
  不提供以隐藏诊断信息为目的的一键清除失败记录。
- “系统维护”是独立页面，组合系统健康、完整性报告、应用数据备份和脱敏诊断导出。它不承担
  媒体库配置、账户或普通浏览偏好。
- 完整性检查先生成缺失索引项、未跟踪媒体和派生缓存报告，再引导调用既有重新扫描或缓存重建
  operation；页面自身不直接解析路径或修改文件。
- 应用数据备份只包含数据库和设置，不包含原始媒体或可重建缓存；计划和保留数量独立保存，
  手动备份显示创建中、校验和可用状态。
- 配置的“扫描”页签使用两个普通数字输入，直接设置后台任务并发数 1～4 和原图/视频读取
  并发数 1～16；默认 2 / 8。沿用共享 `FormField`、卡片与保存操作，不使用资源模式选择卡。
  服务端硬上限始终生效，降低限制不打断现有任务。
- 该交互由 `POST-MVP-1 revision 8` 与 [CR-2026-018](changes/CR-2026-018-explicit-resource-limits.md)
  确认，替代 revision 4 的三档资源模式。
- 本节当前首先约束 `prototypes/` 中的交互。任务中心已拆为
  [FTR-OPS-001](features/task-center.md) 的 `Post-MVP/3` scope proposal，必须按
  `OPS-S0～S4` 后端优先交付；系统维护、完整性、应用备份和诊断包仍是未排期提案，不因
  原型存在而获得生产实现授权。原型总记录见
  [CR-2026-007](changes/CR-2026-007-operations-maintenance-prototype.md)。

## 核心组件

下表定义产品行为，不授权各 feature 分别实现同名控件。跨 feature 原语与模式必须进入唯一共享设计系统；业务组件也必须有明确 owner，具体规则见[ADR-0007](adr/0007-shared-frontend-system.md)。

| 组件 | 必需行为 |
| --- | --- |
| 媒体库切换器 | 同时显示名称与文字状态；键盘可操作；切换后恢复该库上次位置或进入根目录 |
| 目录树 | 延迟加载所有可读取目录，包括空目录；展开不等于选择；显示可用的直接/递归媒体计数并保留当前项、展开状态和清晰层级 |
| 面包屑 | 首尾优先，中间可折叠；每一级是可聚焦链接 |
| 递归开关 | 文案使用“包含子目录”，并在开启时持续可见，不做只出现一次的提示 |
| 媒体卡片 | 稳定占位比例、类型标识、选择/焦点状态；递归或搜索时提供来源路径 |
| 非模态预览 | 单一共享 owner；桌面停靠、窄屏入流；未固定单击切换，固定后单击只选择、双击切换；只保留一个活动媒体 |
| 扫描状态 | 阶段 + 已发现/跳过/错误计数 + 时间 + 协作式取消；总量未知时使用不确定进度 |
| 路径选择器 | 仅显示服务端允许的目录；面包屑、当前位置选择、当前选择和冲突原因均可读屏；根路径显示为 `/library`，提交值仍为允许根相对路径 |
| 确认对话框 | 明确动作对象和后果；关闭后焦点回到触发按钮 |
| 状态横幅 | 用于持续离线、扫描或部分失败；短暂成功才使用 toast |

短暂 toast 默认在 6 秒后自动消失并可提前关闭，避免遮挡后续操作；持续故障和需要用户处理的
状态不得只依赖 toast，必须保留在页面状态或横幅中。

## 视觉语言与 Token 初稿

### 品牌标识

FolioPath 使用统一的极简目录树标识：浅蓝主干、青色中层与蓝色当前路径同时形成
抽象的字母 “F”。标识保持轻盈、连续圆角和小尺寸清晰度，不使用黑色主体、滤镜、
相机或通用文件夹图形。生产界面、首次设置、登录页、应用侧栏和浏览器图标均复用
`BrandMark` 及同一目录树 SVG，不得在 feature 内复制、重新绘制或直接选择品牌资产。
静态交互原型也必须复用这份确认资产：认证后全局 Header 使用 28px 标识配真实
`FolioPath` 文本，480px 以下可隐藏字标但保留图形；登录与首次设置使用 64px 独立标识，
不增加固定底板或改色；所有原型页面使用同一 SVG 作为 favicon。
颜色、净空、尺寸、主题与可访问性规则见[品牌标识规范](branding.md)，确认记录见
[CR-2026-003](changes/CR-2026-003-brand-identity.md)。

### 颜色

颜色使用语义 token，以下值仅用于原型起点，需通过 WCAG 对比度和真实媒体样本验证：

| Token | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `canvas` | `#F5F5F7` | `#000000` | 页面背景 |
| `surface` | `#FFFFFF` | `#1C1C1E` | 侧栏、卡片、面板 |
| `surface-raised` | `#FFFFFF` | `#2C2C2E` | 对话框、浮层 |
| `text` | `#1D1D1F` | `#F5F5F7` | 主文字 |
| `text-muted` | `#6E6E73` | `#98989D` | 次要信息（浅色主题满足 WCAG AA 对比度） |
| `border` | `rgba(0,0,0,.08)` | `rgba(255,255,255,.08)` | 分隔与边界 |
| `accent` | `#0066CC` | `#0A84FF` | 主操作、选中、焦点辅助（浅色主题满足 WCAG AA 对比度） |
| `accent-fill` | `#0066CC` | `#0066CC` | 带白色文字的主按钮填充（满足 WCAG AA 对比度） |
| `success` | `#248A3D` | `#30D158` | 成功 |
| `warning` | `#984B00` | `#FF9F0A` | 扫描警告、部分失败（浅色主题满足 WCAG AA 对比度） |
| `danger` | `#FF3B30` | `#FF453A` | 失败与移除动作 |

状态不能只靠颜色。焦点环使用独立高对比 token，并在深浅主题都达到可见要求。查看器使用独立近黑表面，不继承普通卡片阴影。
浅色与深色主题的三级文字分别与次级文字统一为 `#6E6E73` 和 `#98989D`；
选中项通过背景、正文色和 `aria-current` 共同表达，避免低对比强调色成为
唯一状态线索。

### 字体、间距和形状

- 字体：优先使用 Apple 系统字体栈并回退到 `system-ui` 与中文系统字体；正文 `15/22`，
  密集 UI `13/18`，辅助信息不低于 `11/13`。
- 字重：正文 400–450，标签 500，页面标题 600；不以过多字号制造层级。
- 间距：4px 基准，常用阶梯 `4 / 8 / 12 / 16 / 24 / 32 / 48`。
- 圆角：控件 8px、卡片 12px、面板和对话框 16px、状态胶囊全圆角。
- 阴影：静态结构使用弱边界；悬浮卡片、对话框、查看器工具条和移动面板使用低扩散柔和阴影。
  侧栏与吸顶工具栏可使用带饱和度的半透明表面，并为降低透明度偏好提供不透明回退。
- 触控目标：移动端最小 44×44px；密集桌面控件的可点击区域仍不得小于 32px，并保留清晰焦点。

## 媒体网格、瀑布流与虚拟化

### 两种布局

- **自适应网格：** 已确认默认布局。列宽随视口变化，卡片使用统一比例裁切，最利于快速扫视、键盘导航和稳定虚拟化。
- **瀑布流：** 首发提供并保留原始宽高比，适合混合横竖图；是用户可记忆的布局选项。媒体名称和路径置于可访问标签，不强迫每张卡片永久占用文字高度。

### 实现约束

- 列表必须使用游标分页和虚拟化；不能一次获取或渲染全部媒体。
- 依赖索引中的宽高比预先计算位置并预留空间，避免缩略图加载后跳动；未知比例使用固定占位。
- 不使用 CSS multi-column 实现瀑布流，因为它会破坏可预测的阅读和键盘顺序。DOM 顺序始终等于查询排序，空间方向键可通过布局映射寻找相邻项。
- 虚拟窗口使用有限 overscan；缩略图解码、预取和动画均有上限。不可为每个卡片创建常驻观察器或重动效。
- 翻页失败保留已加载项目并提供内联重试。切换布局或调整窗口时，尽量以顶部可见媒体 ID 恢复位置。
- 列表末端提供可聚焦的“加载更多/正在加载”语义节点，使键盘和读屏用户能理解分页状态。
- 网格选择与焦点不得因虚拟回收丢失；首次打开右侧预览导致网格重新分栏时，以及从查看器
  返回时，均先恢复所选媒体锚点，再聚焦触发项，不能跳回页面顶部。

默认布局和瀑布流首发范围已经确认。缩略图尺寸档位、列宽断点和 overscan 数值由性能原型确定。

## 键盘、焦点与屏幕阅读器

- 页面提供“跳到主要内容”链接；所有按钮使用语义元素和具体名称，不用只有图标且无标签的可点击容器。
- 目录树若采用 `role="tree"`，必须完整实现方向键、Home/End、展开/折叠和当前项语义；否则使用更简单的嵌套导航列表，不能只写 ARIA 角色而无行为。
- S3-101 的生产实现采用语义化嵌套 `nav` 链接而不是不完整的 `role="tree"`：
  展开按钮与目录链接职责分离，根和每个展开节点只请求直接子级，并用 keyset
  “载入更多”保持有界。桌面目录导航固定在 AppShell 侧栏；`≤ 768px` 由同一
  AppShell 侧栏转为抽屉，Escape 关闭并把焦点还给触发按钮。
- 浏览直达地址使用 `/libraries/:libraryId/browse/:directoryId?`。目录选择写入路径参数，
  面包屑每一级都是同一 URL codec 生成的链接；刷新或复制地址后由 directory detail
  的完整 breadcrumb 恢复当前项与祖先展开链。搜索、递归、排序和布局参数仍由后续任务
  加入，不在 S3-101 提前发明 URL 语义。
- POST-MVP/2 revision 2 下，进入或切换目录会重取目标详情、直接子目录和媒体首屏；再次
  点击已缓存目录也不得只显示 15 秒 staleTime 内的旧结果。刷新按钮与目录导航共用唯一
  query-key 刷新 owner，并在请求前裁掉后续 cursor 页。
- S3-102 将递归与排序加入同一 codec：直接模式的规范默认是 `name/asc` 且不写 query，
  递归模式的规范默认是 `recursive=1` + `modifiedAt/desc`；仅非默认排序额外写
  `sort` 和 `order`，cursor 永不进入可复制 URL。切换 direct/recursive 使用目标模式的
  默认排序并生成一个浏览历史项；显式进入“全部媒体”另写 `view=all`，避免根目录开启
  递归时侧栏当前项跳走。排序、刷新和浏览器前进/后退恢复同一查询指纹与导航目标。
- Post-MVP/1 的 `size/asc|desc` 使用同一排序控件与 URL codec；文案明确“从小到大／
  从大到小”，不改变 direct、recursive 或 search 的默认排序。
- 媒体类型分段控件在“全部／图片／视频”文字旁显示选中目录完整数量；图片包含动图。
  数量随 direct/recursive 和目录关键词变化，但切换类型或分页不改变其统计基准。
- 桌面媒体库/目录侧栏宽度使用中央 `clamp(14rem, 20vw, 19rem)` token 随视口调整；
  移动抽屉继续受可用视口宽度约束，不能产生横向溢出。
- 浏览媒体类型由同一 codec 的 `kind=image|video` 表达；省略 `kind` 表示全部。`image`
  规范映射到后端 `image,animated`，`video` 映射到 `video`。类型切换保留当前范围与排序，
  由 TanStack Query 的筛选键自然重置游标；刷新、复制和前进/后退恢复同一类型。
- 递归结果必须显示可读来源目录。来源是用 `Asset.directoryId` 生成的可聚焦链接，
  文案只显示 library-relative path；点击后进入来源目录 direct 模式，不保留递归或旧
  cursor。S3-103 已将摘要替换为唯一共享 `MediaCollection`：默认 grid、记忆
  masonry，二者复用同一 query、item identity 和 TanStack Virtual lanes controller。
  布局属于 `foliopath.preferences.v1` 显示偏好，不进入 URL；每项按索引宽高预留空间，
  未知比例回退 4:3，有限 overscan 随列数集中计算。
- 媒体网格保持 DOM 排序；方向键移动空间焦点，`Enter` 打开，Tab 不遍历成千上万的卸载项目。卡片按钮的可访问名称包含文件名，递归和搜索结果再包含相对目录；内部图片可使用空 `alt` 避免重复朗读。
- 查看器打开时焦点进入可见关闭按钮，关闭后回到触发卡片；`Esc` 关闭、左右键切换、
  `i` 开关基本信息。关闭、缩放、信息、全屏和前后项等工具条按钮获得焦点时仍允许这些
  查看器级快捷键；原生视频、表单控件或可编辑内容获得焦点时不拦截冲突按键。移动端
  基本信息初始收起，触摸打开后仍须保留关闭、前后项和错误恢复操作的可见可达性。
- 对话框和移动面板限制焦点在当前任务内，关闭后返回触发点；背景使用 `inert` 或等价机制。
- 扫描计数使用节流后的 `aria-live="polite"`，不逐文件播报；阻断错误才使用紧急播报。
- 所有文本和控件以 WCAG 2.2 AA 为验收目标，200% 字体缩放和 400% 页面缩放仍能完成核心流程。
- 支持 `prefers-reduced-motion`、`prefers-reduced-transparency`、`prefers-contrast` 和 forced-colors 的可用回退。

## 状态设计

| 场景 | 表现 |
| --- | --- |
| 无媒体库 | 欢迎页 + 创建媒体库主操作 |
| 首次扫描且暂无内容 | 扫描阶段、发现/跳过计数和取消选项；不宣称为空 |
| 后台重新扫描 | 小型持续横幅；旧内容仍可浏览 |
| 空目录 | 文件夹插图可选，核心是“此目录没有媒体”与“包含子目录”操作 |
| 搜索无结果 | 回显查询和筛选，提供清除筛选 |
| 媒体库离线 | 持续横幅、状态文字、重试；保留索引和缓存可见性 |
| 扫描部分失败 | 警告横幅 + 上次成功时间 + 安全错误摘要 |
| 缩略图排队或失败 | 保持卡片尺寸；仅 pending 时有限轮询资产页，terminal 状态停止；没有重新生成契约时不显示假重试 |
| 原文件不可用 | 查看器内错误 + 返回与重试，不自动跳项 |
| API 断开 | 应用级连接横幅；保留当前界面，不显示假空状态 |

骨架屏只用于结构可预测且等待很短的加载；超过合理时间改为明确进度或错误。Toast 不承载离线、扫描或需要用户处理的持续状态。

S3-104 固定浏览状态的优先级：离线媒体库即使资产页为空也显示离线状态而不是普通空态；
已有媒体的下一页失败保留集合与滚动位置，只在集合尾部显示局部错误和重试；首屏失败才使用
页面级 ErrorState。媒体 skeleton 使用 4:3 缩略图和两行身份占位，列密度跟随最终集合，
`prefers-reduced-motion` 下停止 shimmer。failed/unavailable 使用图标、文字和语义色共同
表达，视频遮罩前景使用独立中央 token，浅色与深色均保持可见。
pending thumbnail 的 2.5 秒自动刷新只在最多 4 个已载入 cursor 页内运行；载入第 5 页
后停止周期刷新，避免大集合把全部历史页反复请求。用户继续滚动仍按 cursor 逐页加载，
刷新或重新进入页面从最新索引状态重建首屏。
下一页请求失败时，集合尾部错误会阻止虚拟末端继续自动预取；已加载卡片和滚动位置保持，
直到用户显式选择局部重试。首屏错误仍使用页面级恢复，不与分页错误混用。

UIF-316 将状态展示收敛到以下唯一 owner；页面只能组合真实 query、mutation 或领域状态，
不得为了“做全界面”创建第二套 mock 状态机：

| 状态 | 唯一展示 owner | 真实消费位置与恢复语义 |
| --- | --- | --- |
| loading | `AsyncState.LoadingState`、结构稳定的 `MediaCollectionSkeleton` | 管理页/详情页首屏 query；Browse/Search 媒体集合短时首屏载入 |
| empty | `AsyncState.EmptyState` | 无媒体库、空目录、Search 无结果；空态必须携带当前范围，并提供创建、包含子目录、清除筛选或编辑查询之一 |
| offline | `AsyncState.OfflineState`、持续 `InlineStatus` | Browse/Search/媒体库与扫描；保留可靠索引和缓存，提供重新连接或重试，不伪装为空 |
| error | `AsyncState.ErrorState`、集合尾部局部错误 | 首屏失败显示明确重试；下一页失败保留已加载集合、焦点与滚动位置 |
| conflict | `FormField` 字段错误或 `InlineStatus` danger | 媒体库重名、根目录重叠、ETag/precondition 冲突；刷新最新状态后重试，不覆盖其他窗口的更新 |
| cancel | 扫描领域状态 + `InlineStatus` | queued/running 可协作取消；cancelled 保留上一次可靠索引与已安全提交的新增项 |
| pending | `Button loading`、扫描/缓存任务状态、缩略图占位 | 禁止重复提交；轮询必须有界，terminal 状态停止；不提供没有后端合同的假重试 |
| success | `Toast`（瞬时确认）或 `InlineStatus success`（持续结果） | 保存/创建/清理等 mutation 用 Toast；扫描详情继续由真实 succeeded 状态、完成进度和成功图标表达，避免重复横幅 |

组件工作台 `UI/StateMatrix/Complete` 固定展示上述八类语义，用于主题、语言、断点和
无障碍回归；它只是共享组件合同证据，不持有任何业务状态。danger 使用 `role="alert"`，
其余非阻断状态使用 `role="status"`；状态不可只靠颜色区分。

UIF-317 将组件工作台接入真实 `LocaleProvider` 与中央主题 globals，状态文案不再由
story 写死。发布前矩阵固定为 `zh-CN/en × light/dark × 390×844/768×1024/
1265×800/1440×900`：四档均检查页面级横向溢出，四组语言/主题组合均检查 `lang`、
resolved theme 和 serious/critical axe；reduced-motion 必须把中央 motion token 收敛到
`1ms`，不能由各 feature 自行发明开关。键盘矩阵覆盖提交、对话框、抽屉、预览和 Viewer
的焦点进入/返回与快捷键；触摸矩阵覆盖移动 Viewer、恢复操作、目录抽屉和无 hover
依赖的媒体卡。视觉、输入与自动化证据统一保存在
[`docs/evidence/uif-317`](evidence/uif-317/README.md)。

逐页视觉来源不得再依赖口头记忆。`web/qa/visual-reference-manifest.json` 是生产页面到
Apple redesign HTML、生产路由、适用状态和确定性 fixture 的唯一机器映射；它明确覆盖
setup/login、首次空态、Browse、Search、Viewer、管理四页、新建媒体库与扫描详情。
`npm run check:visual-references` 必须在前端总检查中失败关闭缺页、丢失 source/fixture 或
矩阵漂移。维护和任务中心原型不属于 `FTR-UIF-001`，不得被该 manifest 静默纳入 MVP。

S3-105 将媒体卡片与唯一共享 `MediaPreview` 接通。未固定状态下，卡片的覆盖按钮保持
文件名可访问名称并以 `aria-pressed` 标记当前预览；递归结果的来源链接继续位于其上层，
不会被卡片预览操作吞掉。桌面预览在媒体区右侧停靠，宽度默认 406px、限制在
360～620px，并提供可拖动、可聚焦的垂直 separator；方向键每次调整 24px，Home/End
跳到边界。预览不使用 modal、scrim 或 `inert`，所以父列表仍可滚动和操作。窄于
1024px 时 separator 隐藏，预览以全宽区块进入内容流。图片使用 `object-fit: contain`；
视频使用浏览器原生 controls、playsInline 与 metadata preload；自动播放和默认静音由
两个独立的当前浏览器偏好控制，带声音自动播放被浏览器阻止时保留手动播放。基本信息只展示索引已有
的 library-relative 位置、MIME/类型、修改时间、尺寸、大小和可选时长，不暴露 host path；
详情值在预览宽度内安全换行，长路径和无空格文本不得以省略号隐藏或制造横向滚动。
文件名最多占两行并与类型徽标同排；位置使用独立、左对齐的浅底路径块，使其与短值元数据
形成清晰层级。详情、收藏标签与预览状态共享一个纵向滚动区，按内容自然高度排列；窗口较矮时
不得把详情压缩成单行滚动槽。已有标签使用独立的直接选择控件；新建标签输入只执行创建，
并使用带文字的“新建标签”按钮，窄面板才收为带可访问名称的图标按钮。
S3-106 将上述状态机补齐：未固定时，单击同步选择与预览；固定后，单击只移动选择，
双击才把唯一活动预览切到该项；取消固定时，预览立即跟随当前选择。集合用选择描边和
`aria-pressed` 表达选择，用眼睛标记和独立内描边表达正在预览，不能只靠颜色区分。
固定按钮使用 `aria-pressed`，面板底部持续说明当前是“跟随选择”还是“预览已固定”。
Escape 与关闭按钮都关闭预览，并通过共享虚拟控制器滚回当前预览项、恢复其语义按钮
焦点。图片/视频切换只保留一个媒体节点；视频节点以资产 ID 为 key，切换或关闭时卸载
旧节点并释放浏览器播放资源。桌面停靠与窄屏内容流规则不变，父列表始终可操作。

## 动效与材质

动效参考 [Emil Kowalski 的 Apple Design skill](https://github.com/emilkowalski/skills/blob/main/skills/apple-design/SKILL.md) 中的即时反馈、空间一致性、可中断交互和无障碍原则，但只作为局部交互质量参考：

- 按下即给出轻微颜色或缩放反馈，提交状态紧随动作出现；不加入人为等待。
- 面板、查看器和可拖动移动端 sheet 的进入与退出沿同一路径，并允许用户在过渡中反向操作。常规界面优先无弹跳、短而克制的过渡。
- `prefers-reduced-motion` 下移除滑动、弹性和大范围缩放，改用短淡入淡出或即时切换。
- 查看器工具条或移动面板可局部使用轻度半透明来表达浮层；减少透明度、高对比或性能不足时必须回退到不透明表面。
- 禁止给每个缩略图添加弹簧、视差或持续动画；禁止改写浏览器原生滚动和滚动物理；禁止在普通页面全局使用 `backdrop-filter`；不加入音效或触觉反馈。

建议过渡基线：按压反馈 80–100ms，控件状态 120–160ms，普通浮层 180–240ms。手势驱动动效不以固定时长强行结束，而应从当前画面状态继续；具体实现需经真机和低性能 NAS 客户端测试。

### Post-MVP 视频故事板动效

[FTR-VID-001](features/video-storyboard-preview.md)由共享 `MediaCollection` 唯一实现
视频卡片故事板：

- 只在 `(hover: hover) and (pointer: fine)`、未启用 reduced-motion 且停留 `300ms`
  后启动；
- 资源 decode 前保持 poster，每帧 `500ms`，移出/隐藏/虚拟回收后恢复 poster；
- 同页最多一个活动动画，浏览与搜索不得各自实现 timer/controller；
- sprite 是装饰性视觉替换，不改变 accessible name、DOM 顺序或增加 live region；
- touch、键盘焦点和 reduced-motion 不自动播放；
- grid/masonry、浅/深主题、4/10 帧和横/竖屏必须进入组件工作台与视觉矩阵。

`VSP-S3 Consumer/UI Ready` 已以共享实现、组件工作台、输入模式与浏览器容量证据确认
本设计合同；完整 feature 仍由 `VSP-S4 Integrated Slice Done` 阻断。

## Post-MVP/4 收藏与标签

- 桌面目录侧栏在媒体库状态下方、真实“目录”标题上方增加“快速访问”，顺序为“所有媒体、
  收藏、标签”；移动端使用目录抽屉的相同顺序。收藏和标签不进入目录树，也不使用文件夹图标。
- 收藏页默认跨全部媒体库并按最近收藏倒序，可切换单库、媒体类型、排序及既有网格/瀑布流。
- 媒体卡片右上角使用语义心形按钮；未收藏时在 hover/focus 显示，已收藏和触摸布局始终显示。
  它不能吞掉卡片预览、来源链接或键盘焦点。
- `MediaPreview` 与 `MediaViewer` 复用同一收藏 mutation/state；成功使用既有 Toast 并提供撤销。
- 标签页先显示有界标签列表和媒体数量，进入标签后复用唯一 `MediaCollection`。标签编辑位于
  预览/查看器信息区域：当前标签可移除，尚未使用的已有标签以独立列表或 chip 直接选择；
  “新建标签”输入只创建新标签，不兼任已有标签自动补全或选择控件。已有词表继续有界分页，
  不一次加载全部标签；每个资产保持 20 项可读上限。
- 首版不增加批量选择；标签创建/改名/删除仍需明确语义、键盘操作、44px 移动触控目标和删除
  说明。离线资产保留收藏/标签并显示既有 unavailable 状态。

- 使用具体动作：“重新扫描”“重试连接”“从 FolioPath 移除”，避免“确定”“处理”等模糊标签。
- 路径以媒体库为上下文显示，长路径保留首尾并可复制安全的相对路径。
- 错误先说明用户影响，再给下一步；技术详情只使用稳定错误码，不泄露绝对路径或工具输出。
- 始终区分“没有内容”“尚未扫描完成”“内容可能过期”和“媒体源离线”。
