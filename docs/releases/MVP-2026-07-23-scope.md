## MVP 验收

- `MVP-AC-001`：两个互不重叠媒体库可通过 UI 在双 volume 部署上创建。
- `MVP-AC-002`：越界、重叠和 symlink 逃逸安全失败，原媒体与宿主路径不受影响／不泄露。
- `MVP-AC-003`：目录、当前/递归浏览和重启恢复形成闭环。
- `MVP-AC-004`：中断、部分不可读和离线保留旧索引，后续完整成功扫描才收敛清理。
- `MVP-AC-005`：目标大集合使用稳定游标、虚拟化和有界任务。
- `MVP-AC-006`：受支持图片/视频可按契约查看，不兼容或损坏媒体安全降级。
- `MVP-AC-007`：核心流程支持键盘、移动宽度和减少动效。
- `MVP-AC-008`：移除媒体库只清理应用与派生数据，原目录内容逐字节不变。

## 明确非目标

- `MVP-NG-001`：上传、移动、重命名、删除、整理或备份原媒体。
- `MVP-NG-002`：以应用内相册替代真实目录层级。
- `MVP-NG-003`：视频转码和自适应码率流媒体。
- `MVP-NG-004`：AI、人脸/对象识别、语义搜索和重复检测。
- `MVP-NG-005`：RAW 工作流、图片编辑和完整 EXIF 编辑/面板。
- `MVP-NG-006`：分享、收藏、评分、评论、地图、时间线和历史。
