## 已冻结范围

1. 对已索引图片和视频幂等添加或取消收藏，并按最近收藏时间分页浏览。
2. 创建、改名、删除实例级扁平标签；名称按 Unicode 规范化后不区分大小写唯一。
3. 单个资产最多关联 20 个标签；通过一次原子替换避免部分更新。
4. 收藏和标签资产页支持全部媒体库或单个媒体库、媒体类型及稳定排序。
5. 桌面左侧栏和移动目录抽屉在目录树之前提供独立“快速访问”；收藏和标签不伪装成目录。
6. 卡片、非模态预览和完整查看器共享同一收藏状态；标签编辑由预览/查看器信息区域承载。

## 非目标

- `POST-MVP-4-NG-001`：层级标签、智能标签、AI 分类、人脸或对象识别。
- `POST-MVP-4-NG-002`：相册、评分、评论、历史、地图或时间线。
- `POST-MVP-4-NG-003`：修改原媒体 metadata、生成 sidecar 或把标签写回文件系统。
- `POST-MVP-4-NG-004`：跨实例、多用户或外部标签同步。
- `POST-MVP-4-NG-005`：首版批量选择和批量打标签。
- `POST-MVP-4-NG-006`：用收藏或标签替代真实目录层级。

安全不变量、单容器拓扑、游标有界性、生成客户端边界和后端优先 Gate 顺序全部继承。
