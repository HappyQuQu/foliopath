## 核心对象与状态

### 媒体库

媒体库有五种面向用户的状态：

| 状态 | 用户看到的含义 | 可执行操作 |
| --- | --- | --- |
| `pending` | 已创建，等待首次扫描 | 查看设置、开始或等待扫描、移除 |
| `scanning` | 正在建立或校准索引 | 浏览已索引内容、查看进度、协作式取消扫描 |
| `ready` | 最近一次完整扫描成功 | 浏览、搜索、重新扫描、编辑名称、移除 |
| `offline` | 根目录不存在或不可读 | 浏览保留的索引和已有缓存、重试连接、移除 |
| `error` | 扫描或处理失败，数据可能不是最新 | 浏览上次可靠索引、查看安全摘要、重试 |

**已确定：** 离线、失败、取消或中断不能清空旧索引。扫描失败时，界面不得把“旧数据仍可见”误写成“扫描成功”。

### 浏览上下文

浏览上下文由媒体库、当前目录、是否递归、排序、筛选和当前分页游标或锚点组成，并写入 URL。返回、前进和刷新应恢复同一上下文；URL 不包含绝对文件系统路径。

## 1. 首次启动与管理员进入

### 正常路径

1. 应用完成数据目录和数据库初始化，浏览器显示轻量启动状态。
2. 未初始化的稳定版实例要求创建首个管理员且不提供默认密码；密码至少 8 个 Unicode 字符，
   不要求大小写、数字或特殊字符组合。初始化完成后进入登录页。认证尚未实现的开发预览版
   只能从回环地址或可信认证反向代理进入。
3. 认证后默认进入一个可浏览媒体库的浏览页，不再先经过“浏览”菜单或媒体库管理页；没有
   媒体库时才进入欢迎页，解释两件事：原文件只读；媒体目录需先映射到 `/library`。
4. 主操作为“创建媒体库”，次操作为“查看 Docker 挂载说明”。
5. 创建首个媒体库后进入该库浏览页，并在页内显示首次扫描状态，不强制停留在设置页。

### 异常路径

- `/app/data` 不可写或迁移失败：显示阻断页和可复制的安全错误码；不显示数据库路径、SQL 或堆栈。
- `/library` 未挂载、为空或不可读：仍允许进入设置，但创建流程显示挂载检查说明；不能把容器其他目录作为替代路径。
- API 暂时不可达：保留应用壳，显示“无法连接 FolioPath”与重试按钮，不把它误判为“没有媒体”。

## 2. 创建媒体库与选择路径

### 正常路径

1. 管理员从全局 Header 的账户菜单进入“管理中心”，默认打开“媒体库”，再选择“新建媒体库”。
2. 输入显示名称。名称必填且在当前实例内唯一，避免切换器中出现无法区分的条目。
3. 打开服务端目录选择器。选择器以“媒体根目录”表示 `/library`，只列出服务端确认可浏览的子目录。
4. 用户通过面包屑或逐级目录进入目标位置，选择“使用此目录”。默认说明为“包含此目录及全部子目录”。首版不提供自定义排除规则，但会跳过维护清单中的系统派生目录和回收站。
5. 确认页显示名称、相对 `/library` 的选择结果、递归包含说明，以及“不会移动、修改或删除原文件”。
6. 提交前服务端再次解析路径并检查边界、可读性、符号链接和与已有媒体库的重叠关系。
7. 创建成功后媒体库进入 `pending`，排入首次完整扫描，界面跳转到该库并显示进度。

### 目录选择器规则

- 已被其他媒体库使用的目录，以及其祖先和后代，禁用并说明冲突媒体库名称。
- 不跟随目录符号链接；此类条目不可进入，并提供简短安全说明。
- `/library` 下的嵌套挂载点不可进入或选择；界面只说明此文件夹无法添加并引导选择其他位置，不暴露
  宿主机挂载细节。媒体库的普通子目录仍按默认规则递归包含。
- 不可读目录不可选。目录在浏览后发生变化时，以提交时校验为准并提示刷新。
- 不提供可指向任意绝对路径的文本框。公开请求只发送服务端给出的目录标识或相对路径。
- 空目录可以创建为媒体库；首次扫描完成后显示正常空状态，而不是错误。

### 失败与修正

| 情况 | 界面行为 |
| --- | --- |
| 路径与已有媒体库重叠 | 保留表单，定位到路径字段并指出冲突对象 |
| 目录离线或权限变化 | 保留表单，提示检查 Docker 挂载或权限后刷新 |
| 路径越界或符号链接逃逸 | 拒绝创建，显示稳定错误文案，不展示解析后的真实路径 |
| 名称不合法或重复 | 字段内联校验，焦点移到首个错误字段 |
| 创建请求重复提交 | 禁用重复提交；服务端结果需保持幂等或安全失败 |

首版允许修改媒体库名称，不允许原地修改根路径；更换根路径通过从 FolioPath 移除后重新创建完成。

## 3. 扫描、失败与离线

### 扫描中

1. 媒体库切换器显示状态点，浏览页顶部显示可收起的扫描横幅。
2. 扫描详情显示阶段、已发现目录数、媒体数、跳过数、错误数和开始时间。总量未知时使用不确定进度，不显示伪造百分比或剩余时间。
3. 新发现内容可逐步出现；刷新或离开页面不影响后台任务。
4. 重复“重新扫描”请求显示“扫描已在进行”，不启动同一媒体库的并行完整扫描。
5. 提供“取消扫描”。取消只停止当前任务，保留上次索引及本次已安全写入的新增记录，并明确后续需重新完整扫描。

创建媒体库后立即扫描，应用启动时执行校准，之后默认每 24 小时完整扫描。管理员可在设置中修改周期或关闭定时扫描，手动扫描始终可用。

### Post-MVP/2：自动发现

[FTR-SCN-001](features/automatic-library-discovery.md)已在 `POST-MVP-2` 冻结，在支持的
本地 Linux 文件系统上增加自动快速路径；它不属于 MVP：

1. 用户复制、移入或新建文件/目录后无需点击“重新扫描”；系统在后台安全确认并提交。用户
   进入/切换目录或点击浏览、搜索页的“刷新”后看到新内容；缩略图尚未完成时先显示既有
   pending 状态。
2. 正常的短暂定向校准不显示扫描横幅或成功 toast，避免频繁打扰。
3. watcher 持续不可用时显示 `degraded` 横幅和安全原因；用户仍可浏览可靠索引并手动完整扫描。
4. 掉盘、权限失败、overflow 或批量删除提示不得让内容瞬间消失；系统保留索引并转入
   offline/degraded，等待可靠完整扫描。
5. 设置中的自动发现开关不影响创建、启动、手动或定时完整扫描。

页面不持续轮询、不使用 SSE/WebSocket；精确状态、刷新和导航重取语义以
[`POST-MVP-2 revision 2`](releases/POST-MVP-2-scope-r2.md)为准。

### 成功、失败和中断

- 成功：短暂显示完成摘要和完成时间，随后状态变为 `ready`。
- 部分目录不可读或 I/O 失败：状态变为 `error`，显示“上次索引已保留，内容可能不是最新”，提供错误摘要和“重新扫描”。
- 应用重启导致中断：恢复后显示“上次扫描已中断”，保留索引，并允许启动新的完整扫描。
- 单个损坏媒体：卡片显示可访问的占位状态；不让一个文件阻断整个浏览页面。扫描详情累计安全错误数。

### 媒体库离线

- 保留目录树、索引信息和已经生成的缩略图；全局状态条明确标记“媒体源当前不可用”。
- 未缓存缩略图显示离线占位；打开原图或视频时显示“源文件当前不可用”，并允许返回原浏览位置。
- “重试连接”只重新验证并启动安全扫描，不能先清空旧记录。
- 离线状态不使用仅靠颜色的表达；状态文字和图标必须同时出现。

## 4. 目录浏览与递归模式

### 当前目录模式

1. 用户从媒体库切换器选择媒体库，默认进入该库根目录或上次访问目录。
2. 桌面端从目录树、移动端从目录面板选择目录；面包屑同步更新。
   用户可收起侧栏“快速访问”来增加目录树的可见范围，浏览器记住此选择；展开后所有入口继续可用。
   向下滚动越过页内标题时，浏览操作区以短暂过渡收紧并吸顶，筛选/布局/排序保持可操作，滚回顶部恢复标题。

3. 内容区先展示直接子目录，再展示当前目录的媒体。普通文件夹与压缩包均可显示已有缩略图作为封面；优先取文件夹直接内容，没有时取后代内容。空目录、尚无可用缩略图或封面载入失败时仍可通过图标、名称和数量进入目录。子目录标题置顶，使用等宽紧凑网格，默认展示两行；
   用户通过底部“展开更多目录”查看已加载目录，展开后接近底部自动分页，也可点击“载入更多目录”。“收起目录”恢复两行且保留已加载结果。
   名称最多两行，悬停或键盘聚焦可查看全名；媒体使用用户选择的网格或瀑布流。
   目录树和媒体列表同样在向下滚动接近已加载内容底部时自动追加。下一页失败保留现有内容及提示，用户继续向下滚动或点击重试即可再次请求；未继续操作时不循环重试。
4. 单击媒体在父列表内打开非模态预览，父列表继续可滚动和操作；从预览显式进入完整查看器。
   关闭预览或查看器后恢复原卡片、滚动位置和焦点。
5. 用户可在工具栏输入关键字，按当前目录的直接子目录名和媒体文件名过滤；关键字写入 URL，
   清除后恢复当前目录完整列表。该操作不改变全局搜索词或跳转到搜索页。
6. 工具栏可在“全部、图片、视频”间切换；“图片”包含静态图片和 GIF 动图。类型写入 URL，
   切换时重置分页游标，但保留当前媒体库、目录、递归范围与排序。

### 递归模式

1. 用户在浏览工具栏开启“包含子目录”。
2. 当前目录不变，列表改为当前目录及全部后代媒体，并重置分页游标。
3. 每个结果显示来源相对路径；同名文件必须可以区分。
4. 点击来源路径回到文件所属目录并关闭递归模式；浏览器返回应恢复之前的递归结果。

### 关键状态

- 首次扫描尚无结果：显示扫描状态和已发现计数，不显示最终空状态。
- 扫描成功但目录无媒体：区分“此目录没有媒体”和“包含子目录后有媒体”，可提供开启递归模式的操作。
- 游标失效或索引在加载期间变化：保留已显示内容，提示刷新列表并从稳定锚点恢复，不无限重复或跳项。
- 目录已从文件系统删除但完整扫描尚未成功：仍可出现在旧索引中；访问失败时说明数据可能过期并提供重新扫描。

普通目录默认按文件名自然升序，递归视图默认按文件修改时间倒序；两者都可切换名称、
修改时间或文件大小的升序/降序排序和媒体
类型。名称排序先按来源文件夹分组，再在每个文件夹内按自然文件名排序。自适应网格是默认布局，
瀑布流是可记忆的首发选项。

Post-MVP 的[无缝瀑布流](changes/CR-2026-033-seamless-masonry.md)由浏览工具栏第三个布局按钮
启用，或在通用设置设为默认。图片之间无空隙和圆角，文件名/修改时间不占文字栏；单击预览、
双击切换沿用既有行为。卡片不显示收藏/来源快捷图标，收藏可在现有预览整理区操作。向下浏览时顶部搜索、账户、面包屑和浏览工具区平滑收起，向上滚动或回顶部恢复；输入搜索、菜单和导航操作时保持显示。文件名和来源信息可在预览或
查看器查看。选择即时保存在本浏览器，新开的浏览、搜索、收藏和标签页沿用；随时可切回网格
或普通瀑布流。共享列表上方提供“缩略图大小”滑条，向右放大、向左缩小，刷新及新开浏览、搜索、收藏、标签页面沿用本浏览器保存的大小。

## 5. 搜索

1. 用户在任一认证后主页面的全局 Header 中输入文件名或路径关键字并提交，进入搜索结果页；
   输入立即获得忙碌反馈，查询写入 URL。
   窄屏将工具入口放在第二行，搜索第一行保留输入和提交按钮；键盘从输入、提交继续到第二行人物及工具入口，内容位于完整 Header 下方。
2. 默认搜索当前媒体库，并允许显式切换当前目录（可递归）或全部媒体库。
3. 结果卡显示文件名、媒体类型和媒体库内相对路径。筛选与排序变化重置游标。
4. 单击结果先打开非模态预览；从预览显式进入完整查看器。前后切换遵循当前搜索结果顺序，
   关闭后恢复查询、筛选和滚动位置。
5. 无结果时保留查询和筛选，提供清除筛选；请求失败时保留已有结果并允许重试。
6. 切换到“画面语义”后，Header 提示改为描述画面内容，空状态说明中文/英文描述；
   结果卡标明实际检索方式，语义结果说明相似度排序与 OCR 未接入。再次提交仍保留模式、库/目录和递归范围；
   切回字面模式恢复文件名/路径提示，不混发语义请求或伪造多个命中来源。

中文、大小写、短查询和自然排序的精确匹配规则由 FTS spike 固定；该实现细节不得改变已确认的三种搜索范围。

### 收藏与标签视角

1. 收藏与标签位于快速访问区，只切换当前媒体集合，不进入另一套管理界面；媒体库切换器和
   快速访问保持原位。收藏视角隐藏目录树，只在收藏项旁显示总数；标签视角隐藏目录树，在原
   区域展示带媒体数量的标签墙，并按数量越多字号越大的 5 级规则形成视觉层次。类型与排序
   筛选留在中间工具栏，侧栏不重复。
2. 工作台保持“左侧视角、中间媒体、右侧详情”结构；单击收藏或标签结果使用与目录相同的
   非模态预览、固定、前后项和焦点恢复逻辑。
3. 右侧详情显示当前标签及尚未使用的已有标签；用户可以移除当前标签，或从有界列表直接选择
   已有标签，不需要重新输入名称。若标签较多，使用明确的“载入更多”继续分页，不一次获取完整词表。
4. “新建标签”输入仅用于创建新标签，不兼任已有标签搜索、自动补全或选择。创建成功后，使用
   返回的标签 ID 将它加入当前媒体的标签集合；收藏和标签操作均不修改原媒体。
5. 收藏、标签、媒体类型和排序写入 URL。进入完整查看器后关闭，应返回原收藏或标签集合及触发卡片。

## 6. 媒体查看器

1. 浏览与搜索先提供非模态预览：桌面停靠在主内容右侧，窄屏进入内容流，父列表不被遮罩。
2. 未固定预览时，单击其他媒体立即切换；固定预览后，单击只改变列表选择，双击才切换正在
   预览或播放的媒体。任一时刻最多只有一个活动预览。
3. 完整查看器是从预览显式进入且可直接访问的路由，保留其来源列表上下文。
4. 图片默认适应视口，并支持缩放、平移、1:1 与全屏；视频使用浏览器原生可访问控制并通过 HTTP Range 尝试播放。服务端 codec 推断不预先阻止播放器挂载；只有当前浏览器实际播放失败后才显示封面、格式与失败说明。首版不转码，不提供显式下载按钮。
   GIF 作为原内容图片显示并保留浏览器动画；视频只在 ready thumbnail 存在时使用其作为
   poster，不伪造封面或从客户端抽帧。非模态视频预览默认静音自动播放；管理员可在通用
   设置关闭，关闭后由用户使用原生控件手动播放。完整查看器不继承这一自动播放偏好。
5. 前后操作只在当前目录、递归列表或搜索结果中移动，并进行有界的相邻项预取。
6. 基础信息区显示文件名、相对路径、类型、尺寸或时长、修改时间；MVP 不提供完整 EXIF 面板。
7. 原文件离线、扫描后已删除或媒体损坏时，就地显示稳定错误，不自动跳到下一项，不修改原文件或大范围清理索引。
   离线/缺失/不可读保留上次可靠索引信息；可恢复状态允许重新检查，明确删除不提供无效重试。
   浏览器播放或运行时读取失败只重新挂载当前媒体，不创建第二个播放器。
8. 关闭查看器时回到触发卡片；若卡片已不在当前虚拟窗口，先恢复列表锚点再还原焦点。

键盘基线：预览中的固定、关闭和“进入完整查看器”均可聚焦；完整查看器使用 `Esc` 关闭、
左右方向键切换、`i` 打开信息。焦点位于视频控件、输入框或对话框时不抢占冲突快捷键。
查看器工具条按钮本身不构成冲突控件；查看器根容器接收路由初始焦点，关闭按钮是首个 Tab
停靠点，因此用户无需额外单击即可使用上述快捷键。
MVP 不提供移动端滑动切换或下滑关闭，始终使用可见按钮完成切换和关闭。交互决定见
[CR-2026-001](changes/CR-2026-001-non-modal-media-preview.md)。

### Post-MVP：视频故事板悬停预览

该流程由 [FTR-VID-001](features/video-storyboard-preview.md)确认，并已通过
`VSP-S3 Consumer/UI Ready`；它仍不属于冻结 MVP，完整交付由 `VSP-S4` 阻断：

1. 视频卡片默认继续显示现有 poster，列表不会预先下载全部 storyboard。
2. 在支持 hover 的桌面精细指针上，指针停留同一卡片 `300ms` 后才加载 ready sprite；
   下载和 decode 完成前 poster 保持可见。
3. 卡片按时间顺序每 `500ms` 展示一帧，最后一帧后循环；任一页面最多一个活动动画。
4. 指针移出、页面隐藏、卡片被虚拟化回收或组件卸载时立即停止并恢复 poster。
5. 10 帧后台生成超过自适应预算时自动降级为均匀 4 帧；4 帧仍超时才标记 failed，
   且不原样自动重试。pending、failed、offline 或 decode 失败只回退 poster，不阻断
   单击预览、完整查看器或播放。
6. 触摸/粗指针、键盘焦点和 reduced-motion 始终使用 poster，不模拟 hover 或新增手势。

故事板 hover 不改变已确认的单击选择、双击切换固定预览、前后项和焦点恢复规则。

浏览和搜索的非模态视频预览另外读取两个独立的当前浏览器偏好：是否请求自动播放、是否
默认静音。默认均开启；关闭静音后如果浏览器阻止带声音自动播放，用户使用原生 controls
手动开始。该偏好不改变完整查看器或故事板 hover。

## 7. 从 FolioPath 移除媒体库

1. 管理员从全局 Header 的账户菜单进入“管理中心”，默认打开“媒体库”，再打开目标媒体库操作菜单。
2. 危险操作明确命名为“从 FolioPath 移除”，不用容易误解为删除原文件的“删除照片”。
3. 确认对话框显示媒体库名称和相对根目录，并明确列出：移除配置、索引、任务和派生缓存；原始目录及媒体不受影响。
4. 单次明确确认即可，不要求输入名称。执行期间防止重复提交。
5. 运行中的扫描和派生任务先停止或失效，再移除该库派生数据。完成后跳转到下一个媒体库；若已无媒体库，则返回欢迎页。
6. 失败时保留可识别的媒体库条目并允许重试，不能出现界面已消失但后台仍可浏览的半删除状态。

## 8. 管理中心独立页面

1. 管理员菜单的“管理中心”默认进入媒体库页。左侧分类导航分别打开配置、媒体库、账户、系统日志、
   关于五个独立 URL；刷新、前进后退和复制地址保持当前页面与页签。
2. 通用页加载已保存的主题、语言、默认排序、网格/瀑布流布局、默认固定预览和视频预览
   自动播放偏好；自动播放默认开启。默认排序可选择按视图默认，或文件名、修改时间、文件
   大小的正序/倒序；URL 已明确指定排序时以 URL 为准。修改后显示未保存状态；“恢复已保存
   值”只回滚表单，“保存更改”成功后清除未保存状态。
3. 媒体库页使用“媒体库 / 扫描记录 / 处理结果”页签。媒体库页签提供新建、改名、
   立即扫描、取消扫描、离线重试、查看扫描详情和安全移除。目录选择器
   在提交前禁用重叠、不可读和符号链接目录；名称重复或缺少路径时保留输入并定位错误。
   默认媒体库页签先显示当前已载入媒体库数、媒体数以及可用或需关注数量，再在一个连续列表中
   展示每个库的路径、内容规模、最近扫描和运行状态。仍有后续分页时摘要明确标注“已载入”，
   不把当前页统计误写为全量；用户从同一行进入浏览或展开完整状态，改名与移除保持低强调。
   处理结果可清除当前浏览器已知的失败并随时恢复；清除只改变本地可见水位，新失败仍出现，
   不删除服务端诊断、任务、缓存或原媒体。
4. 配置页使用“通用 / 扫描 / 缓存”页签，分别保存基础偏好、并发设置与扫描计划、缓存配额。
   并发设置直接填写后台任务并发数 1～4、原图与视频读取并发数 1～16，默认 2 / 8；降低
   限制不打断正在执行的任务。扫描任务显示每库状态、进度、目录/媒体/问题计数；
   同一媒体库重复完整扫描不创建并行任务。清空缓存必须确认，并明确索引与原始媒体不受影响。
   打开媒体库状态后，扫描进度与缩略图/视频封面、视频悬停预览进度分开；扫描结束后派生任务

1. 用户继续使用现有搜索入口，在搜索页选择互斥模式“文件名”或“画面语义”；切换模式保留可兼容的
   库、目录、递归和图片筛选，但丢弃旧 cursor。
2. 画面语义模式接受非空中文或英文文本，支持当前媒体库、当前目录（可选递归）和全部媒体库。
   查询文本只用于当前请求，不进入应用日志、任务记录或诊断包。
3. 结果按 `score DESC, asset_id ASC` 稳定排序，复用现有虚拟化媒体集合与非模态预览；客户端不接收

1. “补齐缺失”只接纳缺失、源指纹过期或可重试失败的图片；等价活动任务合并，不创建第二个 backfill。
2. “全部重建”要求确认成本，建立新 generation 并在验证成功后原子激活；开始时不删除旧 generation。
3. “清除语义数据”要求独立确认，只删除选定媒体库的 embedding、索引和相关任务状态，不修改模型、
   原媒体、收藏或人工标签。操作失败时不得留下设置已关闭但部分数据被当作完整索引的状态。

2. 下方最近任务明确为跨库的可恢复记录，合并此浏览器保存的 operation IDs、当前库自动标签设置返回

   不虚构百分比。仅活动任务显示取消操作。
4. 服务端确认任务不存在时，管理员可以移除该浏览器的旧记录；暂时性加载错误只允许重试，不能删除记录。
