# FolioPath 用户流程

## 文档状态

本文定义首个可用版本的交互流程，不代表已经实现。标记含义：

- **已确定**：来自 README、AGENTS 或已接受 ADR 的产品约束。
- **提案**：可作为首版实现默认值，仍可在评审后调整。
- **待确认**：会明显影响范围或交互，需要产品决策。

本文中的“管理员”指有权管理媒体库和应用设置的人；具体认证方式仍待确认。所有界面只显示容器允许范围和媒体库内相对路径，不显示宿主机路径。

## 核心对象与状态

### 媒体库

媒体库有五种面向用户的状态：

| 状态 | 用户看到的含义 | 可执行操作 |
| --- | --- | --- |
| `pending` | 已创建，等待首次扫描 | 查看设置、开始或等待扫描、移除 |
| `scanning` | 正在建立或校准索引 | 浏览已索引内容、查看进度；若开放则取消扫描 |
| `ready` | 最近一次完整扫描成功 | 浏览、搜索、重新扫描、编辑名称、移除 |
| `offline` | 根目录不存在或不可读 | 浏览保留的索引和已有缓存、重试连接、移除 |
| `error` | 扫描或处理失败，数据可能不是最新 | 浏览上次可靠索引、查看安全摘要、重试 |

**已确定：** 离线、失败、取消或中断不能清空旧索引。扫描失败时，界面不得把“旧数据仍可见”误写成“扫描成功”。

### 浏览上下文

浏览上下文由媒体库、当前目录、是否递归、排序、筛选和当前分页游标或锚点组成，并写入 URL。返回、前进和刷新应恢复同一上下文；URL 不包含绝对文件系统路径。

## 1. 首次启动与管理员进入

### 正常路径

1. 应用完成数据目录和数据库初始化，浏览器显示轻量启动状态。
2. **待确认：认证方案。** 若采用内建认证，未初始化实例先要求创建首个管理员且不提供默认密码；若首版仅依赖认证反向代理，则直接进入应用，不显示伪登录页。
3. 没有媒体库时进入欢迎页，解释两件事：原文件只读；媒体目录需先映射到 `/library`。
4. 主操作为“创建媒体库”，次操作为“查看 Docker 挂载说明”。
5. 创建首个媒体库后进入该库浏览页，并在页内显示首次扫描状态，不强制停留在设置页。

### 异常路径

- `/app/data` 不可写或迁移失败：显示阻断页和可复制的安全错误码；不显示数据库路径、SQL 或堆栈。
- `/library` 未挂载、为空或不可读：仍允许进入设置，但创建流程显示挂载检查说明；不能把容器其他目录作为替代路径。
- API 暂时不可达：保留应用壳，显示“无法连接 FolioPath”与重试按钮，不把它误判为“没有媒体”。

## 2. 创建媒体库与选择路径

### 正常路径

1. 管理员进入“设置 → 媒体库”，选择“新建媒体库”。
2. 输入显示名称。**提案：** 名称必填，在当前实例内不允许重复，避免切换器中出现无法区分的条目。
3. 打开服务端目录选择器。选择器以“媒体根目录”表示 `/library`，只列出服务端确认可浏览的子目录。
4. 用户通过面包屑或逐级目录进入目标位置，选择“使用此目录”。默认说明为“包含此目录及全部子目录”。首版不提供排除子目录规则。
5. 确认页显示名称、相对 `/library` 的选择结果、递归包含说明，以及“不会移动、修改或删除原文件”。
6. 提交前服务端再次解析路径并检查边界、可读性、符号链接和与已有媒体库的重叠关系。
7. 创建成功后媒体库进入 `pending`，排入首次完整扫描，界面跳转到该库并显示进度。

### 目录选择器规则

- 已被其他媒体库使用的目录，以及其祖先和后代，禁用并说明冲突媒体库名称。
- 不跟随目录符号链接；此类条目不可进入，并提供简短安全说明。
- 不可读目录不可选。目录在浏览后发生变化时，以提交时校验为准并提示刷新。
- 不提供可指向任意绝对路径的文本框。公开请求只发送服务端给出的目录标识或相对路径。
- 空目录可以创建为媒体库；首次扫描完成后显示正常空状态，而不是错误。

### 失败与修正

| 情况 | 界面行为 |
| --- | --- |
| 路径与已有媒体库重叠 | 保留表单，定位到路径字段并指出冲突对象 |
| 目录离线或权限变化 | 保留表单，提示检查 Docker 挂载或权限后刷新 |
| 路径越界或符号链接逃逸 | 拒绝创建，显示稳定错误文案，不展示解析后的真实路径 |
| 名称不合法或重复 | 字段内联校验，焦点移到首个错误字段 |
| 创建请求重复提交 | 禁用重复提交；服务端结果需保持幂等或安全失败 |

**提案：** 首版允许修改媒体库名称，不允许原地修改根路径；更换根路径通过移除后重建完成。是否需要“修改路径并完整重建索引”列为后续需求。

## 3. 扫描、失败与离线

### 扫描中

1. 媒体库切换器显示状态点，浏览页顶部显示可收起的扫描横幅。
2. 扫描详情显示阶段、已发现目录数、媒体数、错误数和开始时间。总量未知时使用不确定进度，不显示伪造百分比或剩余时间。
3. 新发现内容可逐步出现；刷新或离开页面不影响后台任务。
4. 重复“重新扫描”请求显示“扫描已在进行”，不启动同一媒体库的并行完整扫描。
5. **提案：** 提供“取消扫描”。取消只停止当前任务，保留上次索引及本次已安全写入的新增记录，并明确后续需重新完整扫描。

### 成功、失败和中断

- 成功：短暂显示完成摘要和完成时间，随后状态变为 `ready`。
- 部分目录不可读或 I/O 失败：状态变为 `error`，显示“上次索引已保留，内容可能不是最新”，提供错误摘要和“重新扫描”。
- 应用重启导致中断：恢复后显示“上次扫描已中断”，保留索引，并允许启动新的完整扫描。
- 单个损坏媒体：卡片显示可访问的占位状态；不让一个文件阻断整个浏览页面。扫描详情累计安全错误数。

### 媒体库离线

- 保留目录树、索引信息和已经生成的缩略图；全局状态条明确标记“媒体源当前不可用”。
- 未缓存缩略图显示离线占位；打开原图或视频时显示“源文件当前不可用”，并允许返回原浏览位置。
- “重试连接”只重新验证并启动安全扫描，不能先清空旧记录。
- 离线状态不使用仅靠颜色的表达；状态文字和图标必须同时出现。

## 4. 目录浏览与递归模式

### 当前目录模式

1. 用户从媒体库切换器选择媒体库，默认进入该库根目录或上次访问目录。
2. 桌面端从目录树、移动端从目录面板选择目录；面包屑同步更新。
3. 内容区先展示直接子目录，再展示当前目录的媒体。**提案：** 子目录使用紧凑文件夹卡，媒体使用用户选择的网格或瀑布流。
4. 选择媒体进入查看器；关闭后恢复原卡片、滚动位置和焦点。

### 递归模式

1. 用户在浏览工具栏开启“包含子目录”。
2. 当前目录不变，列表改为当前目录及全部后代媒体，并重置分页游标。
3. 每个结果显示来源相对路径；同名文件必须可以区分。
4. 点击来源路径回到文件所属目录并关闭递归模式；浏览器返回应恢复之前的递归结果。

### 关键状态

- 首次扫描尚无结果：显示扫描状态和已发现计数，不显示最终空状态。
- 扫描成功但目录无媒体：区分“此目录没有媒体”和“包含子目录后有媒体”，可提供开启递归模式的操作。
- 游标失效或索引在加载期间变化：保留已显示内容，提示刷新列表并从稳定锚点恢复，不无限重复或跳项。
- 目录已从文件系统删除但完整扫描尚未成功：仍可出现在旧索引中；访问失败时说明数据可能过期并提供重新扫描。

**待确认：** 默认排序建议为“文件名自然排序”，可切换修改时间；默认布局建议为自适应网格，瀑布流作为可记忆选项。

## 5. 搜索

1. 用户在当前媒体库内输入文件名或路径关键字；输入立即获得忙碌反馈，查询写入 URL。
2. **推荐提案：** 默认搜索当前媒体库，并允许显式切换当前目录（可递归）或全部媒体库；最终范围由 [RQ-005](requirements-checklist.md#rq-005搜索默认范围) 确认。
3. 结果卡显示文件名、媒体类型和媒体库内相对路径。筛选与排序变化重置游标。
4. 打开结果进入查看器；前后切换遵循当前搜索结果顺序，关闭后恢复查询、筛选和滚动位置。
5. 无结果时保留查询和筛选，提供清除筛选；请求失败时保留已有结果并允许重试。

**待确认：** MVP 搜索范围见 RQ-005；中文、大小写、短查询和自然排序的精确规则由 FTS spike 固定，不用未经验证的承诺代替测试结果。

## 6. 媒体查看器

1. 查看器是可直接访问的路由叠层，保留其来源列表上下文。
2. 图片默认适应视口；视频使用浏览器原生可访问控制并通过 HTTP Range 播放。首版不转码，不兼容编码显示封面、格式说明和下载/打开原文件能力是否可用的明确状态。
3. 前后操作只在当前目录、递归列表或搜索结果中移动，并进行有界的相邻项预取。
4. 基础信息区显示文件名、相对路径、类型、尺寸或时长、修改时间；EXIF 深度信息是否进入 MVP 待确认。
5. 原文件离线、扫描后已删除或媒体损坏时，就地显示稳定错误，不自动跳到下一项，不修改原文件或大范围清理索引。
6. 关闭查看器时回到触发卡片；若卡片已不在当前虚拟窗口，先恢复列表锚点再还原焦点。

键盘基线：`Esc` 关闭，左右方向键切换，`i` 打开信息；焦点位于视频控件、输入框或对话框时不抢占冲突快捷键。移动端滑动切换或下滑关闭需在交互原型验证后再确定，按钮关闭始终可用。

## 7. 从 FolioPath 移除媒体库

1. 管理员进入“设置 → 媒体库”，打开目标媒体库操作菜单。
2. 危险操作明确命名为“从 FolioPath 移除”，不用容易误解为删除原文件的“删除照片”。
3. 确认对话框显示媒体库名称和相对根目录，并明确列出：移除配置、索引、任务和派生缓存；原始目录及媒体不受影响。
4. 单次明确确认即可，不要求输入名称。执行期间防止重复提交。
5. 运行中的扫描和派生任务先停止或失效，再移除该库派生数据。完成后跳转到下一个媒体库；若已无媒体库，则返回欢迎页。
6. 失败时保留可识别的媒体库条目并允许重试，不能出现界面已消失但后台仍可浏览的半删除状态。
