## 用户问题与价值

- 用户 / JTBD：在浏览器标签、登录、公共页面和主应用中快速识别同一个 FolioPath 产品。
- 当前问题及证据：生产界面仅使用文本或通用 `ImageSquare` 图标，不能表达目录层级与媒体浏览
  主题，也无法在不同品牌入口保持一致。
- 为什么必须进入目标版本：首个候选已经形成统一 Apple 风格视觉语言；稳定发布前需要一个
  可复用、可缩放且有明确所有权的品牌标识，避免 feature 各自选择图标。

## 范围

- 新增或改变的 FR/NFR：澄清 `FR-UI-007` 的品牌表现，不改变功能行为。
- 明确包含：
  - 三条圆角路径组成的浅蓝、青色与蓝色目录树图形；
  - 唯一纯矢量 SVG 资产和共享 `BrandMark` 原语；
  - 登录/首次设置、公共页头、应用侧栏、README 与 favicon 接入；
  - Storybook、组件测试、类型检查和生产构建验证。
- 明确不包含：产品更名、营销站、动态 Logo、深色主体变体或 API 改动。
- 被替代/延期的现有范围：替代认证页的通用 `ImageSquare` 品牌占位；不延期既有范围。
- Scope-budget exception（如有）：N/A；品牌替换不增加业务能力、后端或发布拓扑。

## 质量属性场景

- 刺激：用户在登录页、应用侧栏或浏览器标签看到品牌入口。
- 环境：浅色/深色主题、桌面/移动布局及 16px favicon。
- 系统响应：所有入口通过同一 `BrandMark` 原语使用同一纯矢量目录树资产。
  产品名称仍由真实文本提供；图形不变形、不重复朗读。
- 可测结果：生产构建包含 SVG；三个语义尺寸通过组件测试；登录、公共页头和侧栏无溢出；
  浅色与深色背景保持可辨识。
