# CR-2026-034：缩略图大小与无文字来源入口

- 状态：Confirmed；2026-10-23 用户指出递归浏览仍有来源文字，并明确要求放大缩小滑条。
- 目标：Post-MVP 1.4.x 显示优化；Stage S3-103/S3-107，Owner：FolioPath maintainers。
- 需求：FR-BRW-014 修正、FR-BRW-015；继承 NFR-ACC-001 / NFR-PERF-002。
- 合同：既有 catalog、curation API 不变；纯浏览器 preferences v1 增加 mediaTileSize。
- Owner：MediaCollection 统一布局/大小控制；preferences.ts 统一校验/保存；UI/Slider 统一原生滑条。

## 接受行为

无缝瀑布流不显示文件名、修改时间或来源目录文字。来源入口改为可访问目录图标，桌面悬停或
键盘聚焦显示，触屏常显；其他布局的文字保持既有行为，预览和查看器仍可查看完整信息。

所有共享媒体列表上方增加“缩略图大小”滑条。向右放大、向左缩小，目标列宽 120–480 CSS px、
步长 10、默认 210；实际宽度自适应，1–16 列，浏览器记忆。支持方向键、Home/End 及触屏拖动。
布局/大小变化触发虚拟化重测，保留查询 DOM 顺序、cursor 和有界 overscan，零间距不变。

## 发布影响与证据

无后端、迁移、原图或部署拓扑变化，不引入 AI 分支内容。纯本地显示，不扩大冻结 MVP。
新原语 UI/Slider 有稳定生产 Story 和可访问行为测试。MediaCollection/偏好测试覆盖无文字来源、
现有动作、记忆及无效值；浏览器矩阵覆盖 390/768/1280/1920、两语言/两主题、缩放后零间距、
无溢出、键盘和刷新记忆。执行结果见 [验证记录](../evidence/gallery-size-2026-10-23.md)。

2026-10-29 用户随后要求无缝卡片不显示收藏/来源快捷图标并滚动收起顶部；当前接受行为由[沉浸浏览修复](FIX-2026-10-29-seamless-immersive-scroll.md)覆盖，上文保留为历史。
