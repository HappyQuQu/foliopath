# FIX-2026-07-30 全局 Header 与管理导航统一

- 类型：已批准 MVP slice 内的例行原型与 UI 导航修复
- 关联范围：`FR-BRW-001～009`、`FR-UI-001～007`
- 目标版本与阶段：MVP / Stage 3–4 界面收敛
- Owner：共享应用壳、全局搜索入口与管理中心导航
- 合同：`docs/ui-design.md`、`docs/user-flows.md`
- 不变量：搜索状态继续写入 URL；媒体库和设置只暴露安全相对路径；退出仍属于认证用户菜单

## 问题

浏览页目录侧栏同时承载目录、搜索、媒体库和设置，搜索页与管理页又分别建立自己的顶部和
侧边结构，造成同一应用内存在多套导航层级。

## 决定

认证后的浏览、搜索、媒体库和设置原型共用一条横跨视口的全局 Header。Header 固定承载
FolioPath 入口、全局搜索和管理员菜单。目录侧栏只保留媒体库切换器与目录树；管理员菜单
只保留“管理中心”和“退出登录”，避免与管理中心的模块导航重复。管理中心默认打开媒体库，
并在 Header 下使用独立分类导航，区分媒体库、通用、扫描与缓存、
账户，并在窄屏转为横向分类条。

## 证据

- 全局搜索可从浏览或管理页面提交并恢复 `q` 查询参数。
- 管理员菜单支持展开、点击外部和 `Escape` 关闭。
- 管理员菜单仅显示“管理中心”和“退出登录”；“管理中心”默认进入媒体库模块，具体模块只在
  管理中心分类导航中出现。
- Header 使用等宽伸缩的左右轨道保持搜索框视觉居中；管理中心取消固定最大宽度，侧栏在
  216–280px 间响应式伸缩，内容区占满剩余可用宽度，并在 720px 以下切换为横向导航。
- 管理中心侧栏采用单层四项导航，统一图标、行高与选中状态；移除“内容与偏好 / 系统”
  分组标签，页内锚点变化同步更新当前项。
- 四个主原型页面只显示一个全局 Header。
- 桌面与窄屏的浏览、搜索和管理页面通过浏览器回归检查。
