# CR-2026-024：INT-S4 屏幕阅读器验收豁免

- 日期：2026-09-02
- 目标版本：`POST-MVP-5` revision 2
- 需求：`FR-INT-001～020`、`NFR-INT-001～010`
- Owner：产品用户
- 影响阶段：S4（`INT-408`）
- 架构影响：无部署单元、技术栈、信任边界、持久化边界或模块依赖方向变化；无需新 ADR

## 决定

产品用户明确要求 `INT-S4` 不需要 VoiceOver 验收。`INT-408` 因此不再要求真实屏幕阅读器操作或
屏幕阅读器 owner 签署；本次豁免只删除这一项人工发布证据，不把未运行的 VoiceOver 测试登记为通过。

键盘顺序、焦点恢复、语义控件、可读名称、双语、缩放/重排和 axe 自动化仍是强制验收项。retail Safari、
三浏览器、大集合虚拟化和物理键盘的现有证据继续有效；物理触控/目标移动设备证据仍由 `INT-408` 持有，
未完成前该主任务保持未勾选。

## 发布影响与回退

本变更不改变 AI 模型、质量、隐私、供应链、双架构或最终镜像 Gate，也不扩大已冻结的用户功能范围。
若后续重新要求真实屏幕阅读器支持，必须恢复对应人工验收，并在获得合格证据前继续失败关闭该子项。
