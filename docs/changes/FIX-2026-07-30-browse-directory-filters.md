# FIX-2026-07-30 浏览页当前目录筛选

- 类型：已批准 MVP 浏览 slice 内的例行原型与 UI 修复
- 关联范围：`FR-BRW-001～009`、`FR-UI-001～007`
- 目标版本与阶段：MVP / Stage 3–4 界面收敛
- Owner：浏览工具栏与 URL 状态
- 合同：`docs/ui-design.md`、`docs/user-flows.md`
- 不变量：当前目录、递归范围、媒体类型、关键字、排序和布局继续由统一 URL codec 持有

## 问题

浏览页缺少当前目录内的轻量关键字过滤；媒体类型入口以孤立漏斗图标放在面包屑右侧，无法直接
表达“全部、图片、视频”，也与目录范围和排序控件缺少清晰关系。

## 决定

浏览工具栏左侧集中放置“包含子目录”和“全部 / 图片 / 视频”，右侧依次放置当前目录关键字、
布局与排序。关键字过滤当前目录的直接子目录名和媒体文件名，并与媒体类型组合；关键字和媒体
类型写入 URL。全局 Header 搜索仍负责跨目录或跨媒体库检索。

## 证据

- 输入关键字时，子目录卡与媒体卡即时过滤，结果计数同步更新。
- “全部 / 图片 / 视频”直接可见，选择状态使用文字、背景和 `aria-pressed`。
- 关键字与媒体类型组合过滤并可通过 URL 恢复。
- 桌面、窄屏与移动端工具栏无横向页面溢出。
