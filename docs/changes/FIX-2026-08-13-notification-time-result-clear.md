# FIX-2026-08-13：通知时间与处理结果清除

- 日期：2026-08-13
- 状态：Accepted / Implemented
- 目标版本：`POST-MVP-3` maintenance
- 关联范围：`FR-OPS-007～011`、`CR-2026-015`
- Owner：`web/src/features/notifications`、`web/src/features/libraries`

## 问题与决定

消息中心只显示事件内容，扫描完成、媒体失败和版本检查缺少可见时间；媒体库“处理结果”也无法
清理已经看过的失败，长期使用后难以聚焦新增问题。

本修复做出以下决定：

- 版本提醒显示检查时间，媒体失败显示最近失败时间，扫描完成显示完成时间；使用当前语言和时区；
- 活动扫描和派生处理没有统一、可靠的开始时间字段，继续显示实时状态与进度，不伪造时间；
- “清除当前结果”保存当前浏览器看到的全局失败修订水位，只隐藏该水位及之前的结果；
- 清除后新产生的失败、或同一任务重新处理后再次失败，因完成时间晚于水位而重新显示；
- “恢复已清除结果”删除本地水位并重新显示服务端保留的诊断；
- 清除不删除 `media_jobs`、attempt history、原媒体、派生缓存，也不改变补齐缺失和重建语义。

## 证据

- 通知组件测试固定版本检查、媒体失败和扫描完成的本地化日期时间；
- 处理结果测试固定清除、持久化水位、恢复与服务端数据不变；
- 偏好测试拒绝非法 revision，仅接受既有 `mfailrev_<time>_<job>` 合同。

无需 OpenAPI、migration 或生成客户端变化。
