# 删除后刷新、目录菜单及文件任务入口修复

2026-10-30；CR-2026-058 / POST-MVP-DELETE / DELETE-S3；FR-DEL-005/007、FR-BRW-016/017；Owner：Web deletion / browse。

用户报告删除后目录残留、“查看文件任务”样式不统一，以及操作/右键菜单中的回收站、文件任务、删除设置没有反应。本次恢复既定产品行为，不新增 API、数据库迁移或文件系统能力；沿用 ADR-0044，不修改 PVE。

- 原提交仅立即失效一次缓存，可能早于后台任务处理；现在跟随刚提交操作的状态，每秒读取未结束任务，阶段变化再次刷新，结束后停止轮询。关闭确认弹窗不停止跟随。分页失效复用 catalog-state 的唯一首屏截断规则，避免重用旧游标。
- 目录树使用临时观察器，缓存失效后没有活跃观察器触发重取；现在根及已展开分支通过原来的最多两个请求加载器刷新，不无界同时请求所有缓存。自动刷新和“重试载入下一页”分别保留各自语义，下一页失败仍保留已显示目录。
- 三项链接补上 React Router 跳转，和既有全局菜单一致；操作菜单、右键和键盘菜单共用实现，修饰键链接行为保持。
- “查看文件任务”复用共享主按钮和图标，与“关闭”按钮对齐；不添加本地按钮样式。稳定 Storybook 新增 AcceptedTask，直接使用生产组件和明确的合成合同。
