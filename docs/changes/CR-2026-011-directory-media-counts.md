在选中目录的“全部／图片／视频”筛选项中显示完整数量。数量遵循当前目录或包含子目录范围
及目录关键词；图片数量包含静态图片和动图，但不受当前媒体类型筛选影响。统计来自索引，
不遍历文件系统、不加载无界资产列表，离线媒体库继续显示最后可靠索引数量。

实现向 `AssetPage` 增加 `counts={all,images,videos}`，SQLite 使用与资产查询相同的
scope/search/date 语义聚合。无 migration、ADR、新部署单元或原媒体写入。

验收：直接/递归/关键词范围数量正确；分页与类型切换不改变总量；中英文数字本地化；
按钮可访问名称包含类型与数量；Go、OpenAPI/生成、前端和集成回归通过。

2026-07-31 同一优化复核将媒体库/目录侧栏的中央宽度 token 从固定值调整为
`clamp(14rem, 20vw, 19rem)`，保持桌面常驻、移动抽屉和既有断点语义不变。
