# 按功能切换上下文侧栏

- 状态：2026-10-24 用户已接受侧栏方案；原型作为历史证据归档，不再维护第二套侧栏实现。
- 正式实施：[UI-2026-10-24-contextual-sidebar](UI-2026-10-24-contextual-sidebar.md)，生产组件与 Storybook 为当前规范。
- 用户诉求：搜索、人物、收藏、标签使用原目录区域呈现各自工具，类似当前生产标签云侧栏。
- 目标：合并后 POST-MVP-5 的体验完善；Owner web / product design。
- 范围：既有 FR-BRW-001/004/007、FR-SRH-001～004、FR-CUR-001～008、FR-INT-009～014；
  不新增媒体写入、收藏分组、自动人物命名、搜索服务或模型能力。
- 原型：`prototypes/layered-workspace`；证据为该目录 `evidence/context-sidebar/`。

## 设计规则

共同保留库选择与快速访问的位置；下方同一块区域按当前功能切换。只有浏览视图显示目录。
左侧用于选择与筛选，主区域用于展示结果，管理标签等编辑任务通过主区域明确入口进入。
侧栏工具独立滚动，管理中心/全功能导览保持可达。手机使用功能命名的抽屉入口及关闭按钮。

| 功能 | 侧栏内容 | 主区域与作用域 |
| --- | --- | --- |
| 浏览 | 原有目录树 | 目录媒体与非模态预览 |
| 搜索 | 范围、文件名/画面语义、类型、日期/排序、重置 | 搜索结果与已应用条件；顶部范围只读摘要，避免另一套编辑器 |
| 人物 | 全局已建立人物、本库未命名组、人物查找/列表 | 按视图展示人物或未命名组及样本；已建立人物不受库选择器误导 |
| 收藏 | 当前库的全部/图片/视频及数量、收藏排序 | 收藏结果；取消收藏后更新计数与空状态，不显示无关旧预览 |
| 标签 | 查找、显示语言、带数量标签云、清除筛选 | 所选标签的图片；点击留在标签工作区，不跳成搜索 |

已建立人物是全局整理，未命名组按库展示；收藏仍是当前库范围。标签仅统计图片（含动图），
显示语言不修改标签ID/名称或触发重新推理。清除条件后明确空/未选状态，不通过清理真实索引实现。

## 现有合同与落地边界

- `SearchPage.tsx` 拥有 URL scope/mode/kind/date/sort；生产移动控件时须复用这个所有者，不能复制查询状态。
- `AIReviewPage.tsx` 分别提供全局人物与按库未命名组；不得混为同一个按库列表。
- `CurationPage.tsx` 的收藏查询带 libraryId，生产标签页已有 `hideDirectoryTree + LibraryTagCloud`。
- `LibraryTagCloud` 已有 alias/locale、安全计数、分页与选中链接，应直接复用。
- 生产适配应使用既有 sidebar slot / `quickAccessDetail`，明确 AppShell 可访问名称、焦点及抽屉行为；
  是否需要 ADR 应在正式共享架构变化前判定，原型本身不改变生产依赖方向。

## 原型验证与限制

- 在390/768/1440/1920px逐项检查四个侧栏；无横向溢出，手机可打开/关闭。
- 验证语义搜索范围联动、全局人物/本库组切换、人物查找、收藏视频筛选/取消后的空状态、
  标签选择/语言变化后相同4张合成图片、筛选在不同功能之间互不覆盖。
- 使用8个合成标签、3个人物/3个组、12项合成媒体。无真实请求、无数据库/媒体读取。
- 部分排序、日期、跨库结果仍为视觉示例；不以这些客户端数据证明生产查询、分页或容量通过。
- 构建和4项静态打包测试通过；浏览器控制台error为0；未重复运行生产工程测试。
- 若用户接受，应同步需求、flow、UI规范、生产组件/Storybook、生成客户端适配与回归；
  接受后的story必须渲染正式组件并归档该重复原型，不能将其视作另一条产品实现。
