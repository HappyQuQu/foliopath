# P5 正式双服务交付实施

范围 POST-MVP-5 / CR-2026-030 / F01～F04、G02；Owner app / inference / deployment / tests。
沿用 ADR-0019、ADR-0020，不增加服务、API 或持久化合同。用户授权实施 P5，不授权部署 server222 或发布镜像。

## F01 第一片

新增根 `compose.ai.yaml` 独立入口，不与单容器 `compose.yaml` 合并。强制显式配置主应用/AI 镜像、部署身份、媒体/数据/缓存目录；禁隐式拉取。只读媒体、只读缓存、禁止自动创建错误源目录；AI 仅内部网络，无媒体/数据库挂载或公开端口。主应用不依赖 AI 健康才启动。

资源采用 P4 小样本已用配置：主应用 1 CPU/1024 MiB，AI 3 CPU/2304 MiB，均禁 swap；私有模型快照 tmpfs 计入 AI 限额，不证明 100k 联合容量。人脸仍须部署方显式提供已有合同要求的身份与阈值，不默认复制测试阈值。

回归入口 `tests/release/ai_compose_smoke.mjs`：实际 Compose、合成媒体、独立临时数据，检查配置、AI 缺席时核心启动、初始化登录、缓存模型激活、运行时资源和网络/挂载、重启持久化。镜像从本地解析为不可变 ID，身份离线读取，不采用 HTTP 首次信任。

F02 损坏/错身份恢复、F03 配套安装升级回退、F04 完整文档与 G02 完整安全复核另行记录，不因 Compose 新增而自动关闭。

## F02 模型故障及恢复验证

为实际 Compose smoke 增加 `--faults`，复用同一个隔离环境，不另造部署路径。测试显式配置两个模型和仅合成测试阈值；空缓存、同长度错误字节缓存、错误预期身份逐一注入，再恢复可信配置。检查 API 不可用错误、旧目录/人脸结果/覆盖率保留、模型身份和代次恢复，以及两种任务实际成功。错误文件仅存在测试临时目录，已复制的原始模型缓存只读。

既有 semantic API 在离线时 `activeGenerationId=null` 是准入合同，并非删除代次；故障时检查覆盖率保留，恢复时检查原代次 ID。不得为通过测试改变此合同。验收证据另列；F03/F04/G02 不随此项自动关闭。

## F03/F04/G02 收口实施

新本地构建两个镜像，使用正式 Compose 配对旧/新版本和停写备份，内部测试网络禁外网。升级不继承旧预处理向量完成数，回退只用旧镜像及升级前备份。安全验证包括认证、CSRF/初始化与登录 Origin 合同、路径逃逸、诊断/日志 canary、派生清除和人工关系清除；不扩展成任意历史版本支持或物理介质擦除承诺。

文档提供配套构建/离线传递/初始化配置/停机升级回退/模型来源及限制；新增空值失败关闭的 `deploy/ai.env.example`，避免伪造模型身份或获批阈值。旧单容器及兼容维护路由保留，不恢复模型商店主线。没有新增功能、前端行为、持久化或生产阈值；本轮 F04 修正文档中的历史接入状态与残留边界表述。
