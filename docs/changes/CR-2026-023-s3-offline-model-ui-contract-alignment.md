# CR-2026-023：S3 离线模型管理 UI 合同对齐

- 日期：2026-09-02
- 目标版本：`POST-MVP-5` revision 2
- 阶段：S3 Consumer/UI
- Owner：产品 / 架构 / 前端
- 关联：`INT-301`、`FR-INT-001～004`、`NFR-INT-003/006/007`

## 背景与决定

S3 清单的 `INT-301` 曾写入“审核源下载进度”，但已接受的 ADR-0013、离线模型包合同和
`api/openapi.yaml` revision 1 明确只允许服务端扫描固定只读 `/models`，没有 URL、上传或下载端点。
按旧字面实现会迫使前端伪造进度，或在没有供应链、恢复、空间和来源合同的情况下新增网络模型获取。

`INT-301` 因此按当前 accepted 合同验收：展示模型包大小、目的、架构、许可证、兼容/拒绝原因；扫描
固定 `/models`；允许 managed copy 或 direct use；通过真实 operation 展示验证、复制、激活、失败、取消
与恢复状态；显式呈现 `insufficient_space`。revision 1 不提供在线下载按钮或模拟进度。

网络审核源与下载进度保留为未来提案。进入目标版本前必须另行冻结来源签名、catalog、断点恢复、配额、
代理、审计和运维合同并更新 OpenAPI。此记录不增加或删除 POST-MVP-5 的 A～E 用户能力，只消除清单与
权威合同的矛盾。发布仍由 S4 的最终模型、双架构、质量、供应链和批准失败关闭。
