# FIX-2026-07-31：当前目录筛选继承递归范围

- 类型：`FR-BRW-010` / `UIF-AC-005` 已批准浏览切片内的查询语义修复
- Gate：沿用已交付的目录范围、FTS 字面匹配、稳定 cursor 与统一 URL codec
- 问题：媒体库根目录带关键字时无法区分“根目录直接媒体”和“当前媒体库搜索”；显式勾选
  “包含子目录”还会形成后端拒绝的参数组合
- 行为：未勾选时只筛选当前目录直接媒体；勾选后筛选当前目录及全部后代媒体；普通目录和
  媒体库根目录使用一致语义
- 合同：库内 `q` 未带 `directoryId` 时，省略 `recursive` 仍表示当前媒体库搜索；显式
  `recursive=false|true` 分别表示根目录直接/递归筛选
- 不变量：目录导航仍只返回当前层的直接子目录；原始媒体只读、可靠索引、cursor 绑定和
  filesystem 安全边界不变
- 回归：覆盖 HTTP 参数解析、catalog scope 规范化、前端 API 参数和“先勾选再输入”交互
