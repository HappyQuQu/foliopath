## 实际滚动预览补验后的最终方案

候选 C 的真实 20 项矩阵确认，允许多行时，在 320/390/768px、中英及明暗主题共 12 项中，打开预览的既有 focus + scrollIntoView 受增高的上下文栏遮挡；1280/1920 的精确初始流程通过。先前对 relative 面板滚动后始终要求顶端高于上下文栏的断言过宽，已修正诊断而不改产品断言，原始结果保留。

最终仅把共享上下文栏的直接文字 span 设为可收缩、单行省略，与已有 Breadcrumbs 和库选择器一致，保持现有上下文栏高度及预览滚动边距契约。完整名称仍保留在 DOM/可访问文字中，查看编辑全名继续使用既有媒体库入口；没有新增 tooltip、JavaScript 截字或动态测高状态。稳定 LongLibraryName Story 仍直接渲染生产组件。

同实际 C 镜像的私有样式对照诊断 20/20 通过，仅作为方案依据，不计为 C 产品通过。最终 D 必须以真正构建的样式完成全新 285 项及 20 项实际矩阵，才能更新 6010。
