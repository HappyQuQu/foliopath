# CR-2026-025：INT-S4 剩余验收未验证关闭

- 日期：2026-09-02
- 目标版本：`POST-MVP-5` revision 2
- 需求：`FR-INT-001～020`、`NFR-INT-001～010`
- Owner：产品用户
- 影响阶段：S4（`INT-401～404`、`INT-406`、`INT-408`、`INT-410～411`）
- 架构影响：无部署单元、技术栈、信任边界、持久化边界或模块依赖方向变化；无需新 ADR

## 决定

产品用户明确要求忽略全部剩余 S4 阻塞项。自本记录起，停止继续取得最终审核模型、governed 质量数据、
最终模型联合容量、供应链材料、角色签署和物理触控证据，也不再重复运行不能改变该决定的验证。

剩余八个主任务统一记为 **未验证关闭（user-waived / unverified）**，保持未勾选且不计入完成分子。
这表示不再继续执行，不表示测试通过、质量达标、风险消失或 Gate 获批。

## 发布影响与回退

S4 的终态为 **Closed Unverified / Release No-Go**：已验证完成 `3 / 11`，未验证关闭 `8 / 11`，继续执行
`0 / 11`。`reviewed catalog` 保持为空，face production composition 和未经签署的 AI 发行 UI 继续失败
关闭；普通只读媒体浏览不受影响。

若未来需要发行 A～E 任一智能能力，必须撤销对应未验证关闭状态，补齐该任务原有证据和批准，并重新
执行 `INT-411` Gate 复审；不得把本记录当作质量、安全、隐私、合规或发布 owner 的签署。
