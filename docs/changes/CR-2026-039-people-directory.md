## 发现与修正

- 预览SQL复用PersonAsset可读关联范围，避免前端逐卡额外拉取照片列表；无在线预览不更改已有人工计数。
- 新预览单测初次依赖浏览器默认语言，实际为英文；夹具改为明确中文偏好，保留正常语言跟随行为。
- 新创建浏览器夹具漏了201 ETag，正式client按合同拒绝确认成功；补齐夹具header，未放宽客户端校验。
- 编辑草稿后清除上一名称的未知响应提示；意图键仍由规范化名称唯一owner维护，避免提示归错操作。
- 主区和侧栏都区分“搜索无匹配”与“无人命名”，不把搜索空页解释成实例没有人物。
- 视觉复核发现长姓名造成其他卡片内容垂直居中；统一卡片顶部对齐，并用照片顶部相对卡片边框的断言覆盖。
- 姓名允许长连续文本，卡片显式换行；三浏览器加入96字符连续英文夹具，不依赖容器裁剪来伪装适配。

## 保留边界

previewAssetId是整张已人工关联照片的派生引用，不是人脸头像、用户选择封面或AI身份结论。thumbnail可能尚未就绪，因此失败明确占位，仍可打开人物详情。计数维持已有bound关联语义，可包括离线库；本页人数不冒充实例人物总数。无新增排序/筛选参数或数据库迁移，不修改旧PeopleList排序/快照策略。

创建重试只保留当前挂载页面的意图，不自动重发请求、不跨刷新恢复；改变规范化名称代表新的创建意图。关闭/重新打开同一弹窗不清除未知请求键，成功才清除。
正式原型：features-intelligence-review--people-directory、--empty-people-directory；目录/分组共用照片预览及创建意图owner。
