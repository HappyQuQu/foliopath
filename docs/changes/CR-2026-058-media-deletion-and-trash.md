## 变更及影响

接受默认只读模式与 opt-in 媒体删除模式并存；有限写入只允许删除、移入回收站及恢复目录项，不授权改写内容或通用文件整理。基础 Compose 保持只读；222/9090 按 ADR-0044 接受显式可写候选升级，其他部署继续 opt-in，保留单媒体挂载、data 卷及所有 AI 覆盖。

设计基线为实例级删除权限默认关闭、回收站默认开启且手动清空，可配置 7/30/90 天；一次有界提交顶层文件/目录，后台持久执行。关闭回收站直接后台删除；关闭总删除权限暂停所有媒体变更但不丢日志。页面覆盖确认、未知响应、部分失败、停止、恢复冲突、旧条目保留和真实进度。

回收不直接 cascade 原资产；回收命名空间允许旧人工状态保留和原路径新文件并存。整个删除子树先隔离再执行，所有读取、扫描及在途派生提交共同遵守，避免删除后复活。永久删除不是可回滚事务，文件系统与 SQLite 依赖有日志的分阶段恢复。

这是信任与持久化边界变更：rw 媒体挂载降低主容器失陷时的原件保护，应用开关不能代替 ro 挂载。Linux 写入边界及并发目录移动的保证须有独立证据。首版不自动支持网络/FUSE/CD2/云盘和 Docker Desktop 媒体写入，不承诺所有存储秒删。原媒体恢复需要媒体备份，单独恢复旧数据库不能撤销永久删除。
