# ADR-0022：人物任务的有界扫描等待与脱敏失败诊断

状态：接受（2026-10-23，用户批准修复解析失败和补齐详情）；范围 FR-INT-009/016 / POST-MVP-5。

## 背景

库扫描状态会使在途人物任务以 library_not_ready 终止，所有终止又被展示成部分图片失败。
原逐图失败只持久化计数，无法解释原因。需要区分暂时扫描、库离线、模型不可用和图片问题。

## 决定

保留现有任务状态机、两部署单元、全局 worker 和 lease/checkpoint owner。在途任务遇到 scanning 时，
释放所有数据库事务，使用可取消计时等待最多 60 秒，每秒复核控制条件并刷新既有租约；超时终止并保存
library_scanning，不无限占用 worker 或自动循环。新任务准入仍要求 ready。离线/关闭/清理立即遵循原终止语义。

逐图失败原因仅保存固定脱敏码，与现有 checkpoint 在同一 fenced 事务提交；不持久化底层异常原文。
读取 faces 合同增加有界诊断摘要，最近任务按当前 generation 选择，样本最多 20 张。
新任务通过任务 ID 隔离上一轮展示，未恢复的逐图标记保留为 missing 候选 fence，避免旧成功结果跳过重建失败图片；
当前图成功才删除失败标记。旧的计数无明细明确承认未知。

## 替代与代价

不采用扫描中无条件继续解析：目录扫描可能改变候选总数，破坏现有 coverage/checkpoint 假设。
不采用无限重试或新增暂停状态：扩大状态机和资源占用；不依赖浏览器本地记录作为完整后台诊断。
等待占用一个既有受限 worker，最长一分钟；超长扫描仍需管理员在扫描完成后显式补齐。
诊断只覆盖新执行的人物解析，不能恢复历史逐图原因，也不等于全能力可观测性或发行验收完成。
