# ADR-0031：融合检索与真实命中来源

- 日期：2026-10-25；状态：Accepted / Implemented and locally verified（用户明确要求按已认可原型完成融合检索；证据CR-2026-035）。
- 范围：POST-MVP-5 / CR-2026-035 / FR-SEARCH-001～003、FR-INT-003；Owner search/catalog/semantic。

## 决定

增加`internal/search`用例 owner，消费catalog的规范化、semantic的查询编码/向量与快照合同。
SQLite adapter按作用域流式提供候选，search拥有唯一来源判定、融合排序与有界Top-K/keyset游标；
API仅调用服务并按ID读取正式资产，不查SQL或文件。没有新服务、索引、迁移或原件读取。

新增`GET /api/v1/search/assets`，all/filename/semantic来源选择，当前库/目录（可递归）/全库，媒体种类与修改时间过滤。
字面归因沿用NFKC/full case-fold/空白分词，所有词须在文件名与库内相对路径联合覆盖；
来源分别标注实际文件名或路径依据；basename词不重复报路径，父目录词和跨父目录/basename分隔的完整相对路径片段可报路径。
语义仅使用当前源/当前活动代次、已启用且在线库的图片向量；cosine>=0.20为本轮固定检索准入值，
不是校准概率/质量承诺。同时有字面与语义证据优先，其次字面，最后语义；层内相似度降序、asset ID升序。
每张资产只生成一个候选，故跨来源天然去重；每页最多200，堆最多limit+1，不截断全库候选或使用OFFSET。

游标用现有AEAD owner，绑定规范化查询hash、模式/范围/过滤、catalog revision、semantic代次/覆盖revision、
实际查询向量hash和末项排序元组；查询/索引/模型变化返回stale，不静默拼接不同快照。
读前后复核快照；查询期间变更不发布混合页。水合资产时核对源指纹/名称/相对路径的内部摘要，避免旧来源贴到变更后的图片。游标不保存查询原文、向量或路径。

all模式在语义关闭/模型不可用时保留字面搜索，明确返回语义来源不可用原因；semantic-only失败显示真实错误。
不重试非法向量/数据库损坏，不把故障当空结果。取消立即中止流式遍历。融合与既有语义HTTP共享准入及限流。

图片语义与filename/path在本次融合；视频仍可字面命中，并保留已有独立视频语义/命中帧入口，
不把视频故事板偷偷当图片向量。OCR没有合同/索引，保持禁用说明，不生成OCR来源或伪造识别文字。
模型、身份、四库索引、人工数据与原6010部署均不由此功能自动重建或替换。

## 验收与替代方案

拒绝浏览器各取第一页再合并（漏结果/分页重复/来源不真实）、无界加载全库、随意合并跨模型向量、标签词充当语义解释。
合成SQLite/HTTP验证来源组合、中文/Unicode、路径/文件名区分、分页去重/排序/失效、作用域/时间/类型、
离线/关闭/服务故障与取消；正式组件Story/三浏览器响应式及真实模型Docker回归后更新清单。
旧assets和semantic/assets端点兼容，新增端点与新浏览器交互不改变旧端点合同。
