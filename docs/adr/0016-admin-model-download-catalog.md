# ADR-0016：管理员配置模型下载目录

- 日期：2026-09-08
- 状态：Accepted for implementation
- 关联：CR-2026-026；POST-MVP-5 模型获取扩展；FR-INT-017/019/020、NFR-INT-007/009/010
- Owner：模型管理 / 部署；HTTP 和前端只消费模型管理合同。

2026-09-09 补充：CR-2026-027 允许后端内置只读候选元数据供选型展示；候选与下载授权清单分离，
不会进入 reviewed Catalog，不提供虚构下载地址或默认激活。以下实际下载信任边界不变。

2026-09-10 补充：[ADR-0017](0017-explicit-model-download-proxy.md) 增加显式受信任出站代理。
以下逐地址 DNS 验证适用于直连模式；代理模式的目标解析/IP 策略由部署代理承担，其他下载约束保留。

用户明确要求在界面下载模型。替代 ADR-0013 revision 1 / CR-2026-023 的“仅离线获取”限制，
保留单进程、模型文件哈希固定、原子发布、离线导入和现有激活验证。

部署管理员可以在 `/app/data/model-downloads.json` 提供最多 16 个精确模型包：名称、来源标签、
manifest、内容哈希、架构、文件 HTTPS URL 及允许的重定向主机。该本地文件属于部署信任边界，
不是浏览器上传或在线发现的第三方目录。启动时冻结其内容；变更需要重启。未配置时明确显示没有
下载来源；无效配置拒绝启动，不静默信任部分条目。项目默认不内置未发布的权重地址。

浏览器只提交目录项 ID；认证、CSRF、幂等键和现有 durable install queue 负责准入。下载和离线安装
共享一个 worker，managed store 先检查配额与余量，流式复制时验证每个文件大小和 SHA-256，成功
后原子发布。模型安装 operation 的 completedItems/totalItems 在提供总量时以字节计；复制/下载同用
copying 阶段。取消关闭在途 HTTP；重启把中断任务标记失败并清理 staging，用户重试重新下载，不宣称
支持断点续传。历史从 SQLite 查询，换浏览器也能看到最近下载。

网络 adapter 只请求清单中的 HTTPS 文件，拒绝 URL 凭据、非标准端口、私有/保留地址、非清单重定向
以及 HTTPS 降级；每次拨号验证解析地址并直接拨号已验证 IP。无外部代理继承，限制重定向、连接时间、
单文件时间和文件大小。公共模型源的内部 CDN 需管理员显式列入重定向主机。

管理员提供模型目录不代表 FolioPath 已完成该模型的质量/发布验收。模型获取与运行能力分开展示，
未编译推理 runtime 的镜像仍可下载/保存模型，但不得显示可启用。人脸发行 Gate、媒体路径边界、
既有质量证据不因本扩展改变。

不采用任意 URL 输入、浏览器传输大权重、运行 Python 转换、默认运营镜像或新部署服务：这些方案
分别引入不确定来源、重复流量、额外运行依赖或未授权的运营工作。代价是首次部署仍需准备真实包来源。

验收：配置验证、HTTP 故障与重定向/私网拒绝、真实流式安装与哈希拒绝、持久进度和取消、OpenAPI
消费者、中英文界面与浏览器状态验证。只记录实际执行结果。
