## 决定

- `internal/curation` 拥有固定类别 JSON（稳定英文 key、中文/英文显示名、检索/人工保护别名）。
  API 返回可选本地化元数据，标签原名、ID、计数和关联保持不变；人工原文不做推测式翻译。
  来源混合的全局标签保留原文，单图按该关联的来源投影。展示偏好归现有浏览器偏好 owner。
- SQLite adapter 仍唯一拥有提交事务，复用 curation 的别名策略识别人工标签/移除抑制。
  不迁移、重命名、合并用户已有标签；不把旧建议解释成自动结果。
- 扩充 JoyTag 使用 FolioPath 独立 photo-tag overlay，固定相同模型字节和新类别策略摘要。
  新运行身份包含全部 overlay 执行文件与词表；旧搜索/人物与 legacy 标签代码字节保持不变。
  共享现有唯一 scheduler 和受期限控制的 child，wrapper 在非标签请求 exec 原 worker；不增加
  HTTP 监听、队列、服务或未经验证的常驻模型。新策略返回同一 v1 标签 wire，身份必须重新核验。
- 新策略完成度以新身份计算，旧标签可在补齐前继续显示；不承诺无重跑的识别扩充。

## 替代方案与后果

批量翻译存储名称会破坏人工原文及删除抑制；前端仅凭英文名猜测来源会误翻人工标签，均拒绝。
把新策略覆盖 legacy 文件会无故更换搜索/人物身份，故采用能力独立 overlay。
人工明确创建的同义标签不强制全局合并；保护别名可以防止同图追加重复 AI 类别，但不是任意自由文本
同义词理解。扩充词表不等于更高准确率；须分别记录合成功能与真实质量证据。
