# ADR-0037: OCR全文索引与融合搜索

状态：接受；2026-10-26；CR-2026-051 / POST-MVP-5 S2；owner：search / OCR / SQLite。

## 决策

OCR结果是源绑定派生数据。SQLite在OCR结果与checkpoint的同一事务更新独立全文文档（NFKC/casefold沿用catalog），FTS5 trigram只筛选至少三字符词，instr保证所有词的字面语义并支持一、二字中文。不使用FTS排名或浏览器首屏拼接。升级时按有界批次从已有ready结果回填，不重新推理、不自动启用。

search只读取部署显式OCR identity、库已启用且非clearing、库ready、当前图片源指纹一致的ready结果。OCR关闭、换代、清理、库状态或源更新通过事务内revision使已有游标失效。请求完成及HTTP资产hydration后再次核对快照；存储文字可在AI离线时检索。未配置OCR不暴露历史文字。

all模式保留原字面+语义排序，OCR也属于精确字面命中（同档，不按命中来源数量加权）；OCR与语义同命中优先。OCR-only不调用语义编码。重复图片只返回一次，保留真实来源数组。所有搜索范围/种类/日期和有界heap/keyset适用；视频不推断OCR。

公开证据只返回匹配行的1-based行号及最多160 Unicode字符的原始片段（最多8条），不返回内部身份/绝对路径/整份结果或识别置信百分比。跨行多词按整份文档AND，片段截断不代表全文；明确提示只展示部分识别文字。原始文本以文本节点呈现，无HTML执行。OCR覆盖只统计当前请求范围中已启用、当前identity的图片，未完成和失败不冒称索引完成。

## 影响及替代

新增00047派生索引迁移；OCR写入者仍拥有事务，search不触发分析或修改人工数据。复用catalog revision并增加OCR/源/库状态触发器，不另造任务/队列。保留旧语义/人物/tag身份与向量。拒绝仅扫描JSON全文、只英文分词或直接将识别分数当融合相关度。全局revision会保守地使无关范围游标失效，以正确性优先。

验证：事务/回填/短中文/特殊字符/源换代/清理/关闭/范围/游标与并发失效；真实OCR→索引→HTTP证据隔离Docker；正式组件Story、响应式与无障碍。容量、90°识别质量和6010部署仍独立。

## 兼容审查

反向移除本CR新增字段/enum/说明/marker可逐字节还原CR-2026-050合同（sha256:63b5e0e8592598d198596d65de88cbad7c0a7bf510c47b6f007cb7110a5da75f）。oasdiff严格WARN门仍指出1项response enum增加ocr；这是用户已要求的具体来源扩展，可能影响旧客户端穷举。接受在此未发行POST-MVP-5切片中协调API与生成内嵌SPA更新，旧游标有意换audience v2；不更改全局兼容政策、不伪称WARN门通过，不单独部署后端到原6010。
