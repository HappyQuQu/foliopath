> 2026-10-30 后续用户决定：新删除直接永久删除，仅一次弹窗确认，不再输入确认词或额外勾选；移除回收/保留期设置，移除回收站页面与接口，历史文件及记录不自动清理。文件管理统一管理中心样式。当前基线见 [CR-2026-060](../changes/CR-2026-060-direct-deletion.md)。旧回收设计和阶段记录保留为历史。

# ADR-0044 简化媒体删除执行

- 状态：Accepted，2026-10-30。用户明确要求撤掉多余内核隔离、不动 PVE，完成后升级 222 的 9090，直接使用删除和回收站。
- 范围：CR-2026-058 / POST-MVP-DELETE；取代 ADR-0043 的 Landlock 和私有子进程要求。Owner：files / deletion / app。

files 在主进程既有后台任务内执行同文件系统回收、无覆盖恢复和有界分批删除，不启动媒体变更子进程，不要求 Landlock，不调整宿主内核或启动配置。保留 openat2、相对路径校验、单媒体挂载、库根保护、符号链接及跨挂载拒绝。普通扫描、浏览和分析仍只读。

已知限制：其他程序在删除期间不能移动同一目录及其父目录。openat2 约束打开时的路径，不能阻止已打开父目录被其他写入者移到媒体根之外后的 rename/unlink；不再声称覆盖该竞态。用户在说明该简化约束后明确选择本方案。不为此增加重复路径检查或新的隔离层。

原 HTTP、数据、回收站命名空间、后台进度和故障恢复合同不变。删除默认关闭、回收站默认开启且手动清理；222 的本次明确授权包括启用删除和回收站，允许在停机备份后通过一次性本机管理操作调用同一 deletion 设置服务，不修改管理员凭据或放宽 HTTP 认证。其他部署保持显式 opt-in。

222 使用本次验证的原生 amd64 候选镜像升级；这是指定实例的部署例外，不等于正式发布或双原生、100k/10k 容量验收通过。先完成合成回收/恢复/永久删除及重启恢复验证、完整停机备份和恢复验证，再切换既有 9090，保留 AI、原账号及原数据。PVE 不作任何变更。
