# ADR-0028：显式版本化的大 PNG 语义输入

- 日期：2026-10-23；状态：Accepted；候选已完成本地合成验证，未发行。
- 用户随后明确同意：当前任务结束、完整备份后再切换并重算图片语义索引。2026-10-24已在原任务全部终态、停写全备份核验后更新6010；09:16四库全部终态，8700项中8690成功、10源输入失败。22张目标PNG新代次向量及当前源指纹全部核验；旧向量及人物/标签数据摘要保持不变。仅关闭本次语义输入修复与重算跟进，不宣称源文件恢复、标签修复或发行通过。
- 范围：POST-MVP-5 / CR-2026-032 / FR-INT-002/003/009；Owner semantic/imagevips/app。
- 前置证据：[13 张 PNG 输入阻挡](../changes/INV-2026-10-23-semantic-png-limits.md)。

## 决策

1. 不修改现有 `foliopath-remote-image-v3` 合同。部署 JSON 增加可选 `image_preprocessing`：
   未设置保持 v3，唯一新值 `png-v4`；未知值失败关闭。仅控制语义编码器，不影响人物和自动标签。
2. 新 profile 仅扩展 PNG：源最多 64 MiB、最多 40,000,000 像素，仍遵守公共最大边长；
   在 native load 前从最多 1 MiB 头读取尺寸并验证。Linux 文件使用已安全打开的 FD，
   不重新解析原媒体路径、不 mmap 原件、不生成输入持久副本。非文件流使用现有精确读取与取消/空读预算。
3. 扩展 PNG 继续使用 ADR-0024 的唯一大图 native-memory 槽，在压缩/native 分配前准入，
   在 ImageRef/thread/空闲页清理后释放；不增加并发、取消保护或容器内存限额。
   既有 JPEG/WebP/GIF 限制不变，JPEG 的恢复规则不扩展到 PNG。
4. 继续由同一 encode owner 输出首帧、autorotate、sRGB、去 alpha、uchar、Lanczos3、长边 1024、
   strip PNG、最多 8 MiB。小图旧新路径应像素/输出一致，但输入接受范围属于合同，仍产生不同语义身份。
5. 新 contract hash 形成新 semantic generation；旧向量保留原身份，不复制或重标为新结果。
   默认不切换、不自动重建；原 6010 任务运行期间先交付候选与合成验证。部署切换应在任务终态、
   完整停写备份及明确重算范围之后执行，按既有新代次 missing 作业补齐，不清理人工整理。
6. 自动标签继续用固定 v3 preprocessor 和其已有 fingerprint。扩充 PNG 自动标签输入需要独立变更，
   不借此次语义修复改变旧 92 类或新 153 类标签任务。

## 替代方案与后果

- 直接增加旧常量：会让身份字符串与执行行为不一致并影响标签任务，拒绝。
- 把当前 13 张转成 JPEG 或改原文件：违反只读原件，拒绝。
- 自动把旧向量导入新代次：改变持久一致性并掩盖重算，本次不做。
- 新代次需要重新计算已有图片；这是显式兼容性代价，不把旧覆盖率算到新版本。
- 40 MP/64 MiB 是本切片待测的有限边界，不承诺任意大 PNG、默认全系统资源预算、长期/跨架构或发行通过。

## 必需证据

纯合成 PNG（约 17 MP 且 >32 MiB）、上界/越界、截断与伪造尺寸、alpha/16 位、文件与内存流、
取消/无进展、重复解码与 native 引用回收；新旧语义身份区分、默认 v3 及人物/标签身份不变；
本地 Docker 固定 native 构建与真实模型合成索引/查询/重启/旧代次保留。没有证据的阶段保持未完成。
