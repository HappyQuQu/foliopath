# ADR-0021：有界模型进程与自动标签原子提交

- 状态：Accepted for implementation，2026-10-22；不等于测试或发行通过。
- 依据：用户确认 CR-2026-031，并要求解决模型内存、自动打标、人工保护及本地 Docker 验证。
- 范围：POST-MVP-5，FR-AUTOTAG-001～003；Owner：Codex。

## 背景

同预算实验已经确认四个搜索/人脸会话与 JoyTag 共驻会触发 OOM。仅删除 Python 引用不能证明
ORT 原生内存释放。旧候选词评分、建议审批不满足用户要求的直接图片标签。

## 决定

1. 保持主应用与 AI 服务两个部署单元。AI HTTP 父进程拥有唯一推理调度器及校验后的私有模型
   快照生命周期；最多一个实际推理子进程和一个等待请求。启动验证完整 manifest 后释放暂存，
   每次请求只对当前能力族的完整固定 manifest 子集重新 hash-copy 到专用私有 tmpfs 目录；
   身份仍绑定完整部署 manifest，不跳过任何所用字节校验。校验/复制/加载/推理均受同一个
   可终止的子进程期限约束，不使用取消后仍运行的复制线程；父进程在回收 child 后清理专用目录。
   子进程只加载本次能力需要的模型，每次请求
   完成、失败、取消或超时后退出并 wait 回收。26 秒总期限包含排队，不在后台遗留推理。
   保持现有 2304 MiB RAM / 1200 MiB 快照限制；吞吐与冷加载开销必须实测。
2. 自动标签使用独立 `foliopath-tag-v1` 身份与图片推理协议，固定模型、输出过滤策略及摘要。
   输出最多 20 个客观类别，分数不是校准概率；不接受用户候选词，不推断敏感身份特征。
   运行时代码改变会改变身份，不能把旧搜索/人脸索引静默当成新身份兼容。
3. `internal/autotag` 唯一拥有库级开关、任务准入、租约、取消和增量调度；复用现有
   `jobs.WorkerPool` 与共享 `resourcecontrol`，不增加部署 worker。每库最多一个活动任务、
   全局最多 32 个，候选 keyset 分页且记录准入上界，单图推理不持数据库事务。
   启用和启动唤醒、每 30 秒有界扫描已启用库以补新图/源变化/模型变化；同源同模型失败不
   自动无限重试：系统级失败或取消后持久阻止该模型身份再次自动准入，显式启用或 all 重跑
   才解除；模型身份变化可重新准入。显式 all 重跑须确认。关闭/取消后禁止新提交，已提交结果保留。
   共享推理槽暂忙不是模型故障：同图最多 3 次尝试，间隔 1/2 秒且可取消；仍忙则同一任务/operation
   持久延后 30 秒再准入，不写空标签、不推进 checkpoint、不创建新 operation，不写模型阻断。
   延后原子提升 claim fencing 并退还本次 crash-attempt，保留此前崩溃计数；关闭/取消可立即结束
   延后队列，旧 claim 不得提交。暂忙身份探测保留既有 ready，首次未知仍不可声称可用。
4. `internal/curation` 唯一拥有标签规范化和人工保护策略。`asset_tags` 是可见关联唯一来源，
   旧关联默认 manual；AI 合并仅替换 AI 关联，永不删除或降级 manual。人工移除写持久的
   (library, asset, normalized name) 抑制，重跑/模型更新/标签 ID 重建不能绕过；显式人工添加
   清除同名抑制。既有人工标签编辑改差量更新，保留未变关联来源。
   全局删除为当前已关联图片写同名抑制；不代表禁止未来图片出现此类别。全局改名将现有
   AI 关联提升为人工，抑制旧名，保留新名；与单图操作一致尊重显式人工整理。
   catalog 源 fingerprint/种类变化使旧 AI 关联失效但保留人工与抑制；worker 仍须验证实际
   打开前后媒体身份，数据库 fingerprint 本身不是文件内容不变的证据。
5. SQLite adapter 在一个有界写事务中检查任务租约、取消、开关、模型和源文件 fingerprint，
   调用 curation 拥有的合并策略，再写结果、任务 checkpoint 与 operation 计数；不把它拆成
   可部分成功的两个事务。人工编辑仍用 revision CAS；读取 curation 使用一致快照。
6. 所有媒体只读、通过已有 files/media 边界读取；所有设置、来源、抑制和任务在 /app/data。
   迁移只追加。公开 API 归 OpenAPI，内部标签身份与推理合同归版本化适配器和回归测试。

## 替代方案与后果

- 拒绝未经验证提高内存、永久共驻或依赖 GC；进程回收提供操作系统级资源释放，但冷加载增加延迟。
- 拒绝自动批准旧候选建议：其模型语义、生命周期和人工保护不同。
- 不新增外部队列或部署服务；共享 SQLite 事务由 adapter 组合，业务包不互相导入实现。
- 固定输出类别是安全过滤而非用户词库；普通照片的准确率与语言体验仍须独立验证，功能测试不
  等于模型质量、跨架构、全量回归或发行验收。

## 必需证据

同预算至少三轮真实 text → image → face → tag 推理及回收；无 OOM、无残留子进程。
人工删除/恢复/重跑/并发/旧库迁移、源变化、取消、服务异常、重启恢复需自动回归；本地独立 Docker
用合成媒体经鉴权 API 验证标签产生与保护并校验原文件 hash 不变。进度文档只记录实际结果。
