# ADR-0043 Linux 媒体变更子进程隔离

- 状态：Superseded by [ADR-0044](0044-simple-media-deletion.md)，2026-10-30 用户明确撤回内核隔离、要求不动 PVE。下文为原决策及历史证据，不再约束当前实现。
- 原接受记录：2026-10-30。DELETE-S1 真实 Linux 复现已打开父目录被外部移出后的写入逃逸；用户选择“增加内核写隔离；不支持的系统保持只读”，授权预计额外 400～800 行隔离、通信及验证实现。
- 范围：CR-2026-058 / DELETE-S1；补充 ADR-0042 的写边界，不增加部署单元。
- Owner：files 独占 Linux 隔离与描述符媒体变更；deletion 仍拥有业务和持久任务，app 组合。

## 背景及证据

独立 Linux arm64 容器、无网络/无能力、仅合成 tmpfs 内，`TestDeletionBoundaryOpenedParentAfterExternalMove` 复现：openat2 打开的目录在被外部程序移出媒体根后，重新从根读取会失败，但通过旧父描述符执行 unlinkat 或 renameat2 仍会改变根外文件。触发要求另一个写入者在该窗口移动父目录，实际发生频率未测；不是通过重复 pathname/设备号检查可以消除的保证。

原候选复现之后，受限子进程已通过同场景阻止及库内正常操作的原生 arm64 合成验证，见 DELETE-S1/S2 Gate；不等同容量、生产镜像或双原生发布验证。测试和输出保持本地专用。

## 决策

媒体变更在主镜像内启动一个有界、请求/操作关联的内部子进程，复用现有主程序私有入口；不是 HTTP 服务、后台部署单元或特权守护进程。主应用持有 SQLite、认证、资源准入、任务/心跳和取消，子进程没有数据库或独立队列。

子进程在执行媒体变更前，将实际操作线程固定并应用 no_new_privs 与 Landlock 写访问规则；仅允许固定媒体根下被授予的目录项操作，禁止内容写入/截断及根外目录项变更。沿用 openat2 的 beneath/no-symlink/no-xdev 解析及无覆盖 rename；Landlock 不能替代路径锚定、源身份、根保护或业务确认。继承的描述符仅限通信和已锚定根，不继承任意可写文件。

父子使用有界内部协议传递操作意图及阶段结果，不能接收浏览器命令、宿主路径或 shell 片段。只有应用已持久化且通过 admission 的用例能启动变更；取消/进程退出须回收子进程后释放资源。应用普通扫描、浏览、分析不取得此入口。

Landlock 或必需规则/系统调用不可用时失败关闭，删除功能不可启用，不降级为普通 rename/unlink。默认部署继续 ro；不扩大 capabilities、不挂 Docker socket、不增加媒体挂载，不把开发平台适配器当原生发布证据。主进程仍需 rw 媒体挂载才能启用此能力，因此不能声称主进程失陷时获得 ro 挂载的原件保护。

## 验证及后果

S1 必须证明同样的“父目录移出”实验在子进程内被内核拒绝，且库内正常回收/恢复/删除、符号链接/嵌套挂载拒绝、内容写入/截断拒绝、隔离不可用失败关闭、取消回收和通信上界均可验证。使用支持 Landlock 的原生 Linux 内核；Docker seccomp/LSM 必须允许必需系统调用，不能通过 privileged 或关闭 seccomp 获得虚假默认部署证据。

增加子进程生命周期、内核兼容性和内部协议维护成本；资源由既有任务准入限制，并发不增加。Linux 内核官方 [Landlock 文档](https://docs.kernel.org/userspace-api/landlock.html)提供语义依据，实际最低 ABI、系统调用规则和支持矩阵由 S1 原生证据固定，不能按内核版本字符串推断可用。
