# ADR-0010：经认证的局域网 HTTP 与可选外部 TLS

## 状态

已接受（2026-07-28）；修订 ADR-0005 的部署传输解释，不改变内建单管理员认证决定

## 决策角色

- 产品：确认家庭服务器和受信局域网是首要部署环境
- 架构：保持单容器、单进程、单 HTTP 端口
- 安全／发布：保留认证、CSRF、转发头清除与可选可信代理边界

## 背景与备选方案

现有候选要求所有非回环监听都位于可信 HTTPS 代理后。这保护链路，但迫使主要 LAN 用户维护
额外部署单元，与 `FR-DEP-001～003` 的简单部署目标冲突。评估了三种方案：

1. 继续强制 HTTPS 代理：安全最强，但把外部基础设施变成最低启动条件，拒绝。
2. 增加匿名 LAN 模式：会暴露私人媒体并绕过现有认证，拒绝。
3. 支持经单管理员认证的直接 LAN HTTP，同时保留可选代理模式：选择。

## 决策

- 数值非回环地址是合法监听地址，不要求同时配置可信代理 CIDR。
- 没有可信代理配置时，请求以直连 peer、原始 Host 和真实 TLS 状态建立 transport；
  所有客户端提交的 `Forwarded` / `X-Forwarded-*` 声明在进入业务处理前清除。
- 非回环监听同时配置 `FOLIOPATH_TRUSTED_PROXIES` 时，表示部署者显式选择代理专用模式；
  非可信远程 peer 失败关闭，可信 peer 必须提交严格单跳 HTTPS transport。
- 推荐 Compose 默认发布 `0.0.0.0:8080`，同时提供宿主绑定地址变量以收窄到回环或指定 LAN IP。
- HTTP 模式仍要求首次设置单管理员、会话、业务 API 认证、CSRF、SameSite 与 HttpOnly Cookie。
  Secure Cookie 和 HSTS 只在真实或验证后的 HTTPS transport 启用。
- FolioPath 不新增 TLS、证书或反向代理部署单元。部署到公网或其他不可信网络时，部署者必须在
  FolioPath 外提供 TLS 与访问控制。

## 后果

家庭服务器可用两个 volume 和一个端口直接启动，局域网浏览器可完成初始化与登录。代价是
HTTP LAN 流量不具备传输机密性，部署者必须正确判断网络信任边界。现有严格 HTTPS 代理能力和
安全头语义保留，但不再是所有非回环部署的前置条件。

## 验证与复审

- 对应 fitness function：`AF-013`。
- 证据：配置单元测试、transport 伪造头测试、HTTP auth/CSRF 测试、Compose smoke。
- 需要复审：引入多用户/分享、浏览器弃用 HTTP Cookie 能力，或 FolioPath 自带 TLS。
- 替代关系：仅替代 ADR-0005 和 S5-003 中“非回环必需代理”的部署解释。
