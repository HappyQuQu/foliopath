# ADR-0005：稳定版内建单管理员认证

## 状态

已接受（2026-07-23）

## 背景

FolioPath 的部署目标是一个容器、一个端口，并把媒体库和业务设置放在 Web 界面完成。如果稳定版只支持外部认证反向代理，用户仍需部署和维护额外认证配置；如果允许匿名局域网模式，错误端口映射又可能暴露全部私人媒体。

产品确认选择：开发预览版在认证完成前只允许回环地址或可信认证反向代理；首个稳定版内建首次设置的单管理员账号、会话和退出登录，不提供匿名局域网模式。

## 决策

- 稳定版首次启动进入受限初始化状态，只能原子创建一个管理员，不提供默认账号或密码。
- 初始化完成后再次创建管理员的入口永久关闭；MVP 不提供多用户、角色或访客访问。
- 除健康检查、认证状态、首次初始化和登录外，媒体、搜索、扫描、媒体库、设置及原文件内容接口都要求有效会话。
- 使用可撤销、可过期的服务端会话和安全 Cookie。所有状态修改请求实施 CSRF 防护或等价的同源令牌设计。
- 登录、初始化和会话端点实施限流、错误脱敏和安全审计；退出、密码变化与安全事件可以撤销会话。
- 认证完成前的开发预览版默认只绑定 `127.0.0.1`，或置于可信认证反向代理之后；它不是可直接局域网/公网发布的构建。
- 反向代理仍可负责 TLS、域名和额外访问策略，但应用不能把“部署者应该配置代理”作为跳过稳定版认证的理由。
- 密码哈希算法/参数、Cookie 名称、会话期限和 CSRF 令牌细节由安全设计和测试固定，不在本 ADR 中锁死具体库版本。

## 后果

- 默认部署仍保持一个 FolioPath 容器，管理员可以在界面完成初始化，不强制增加认证服务。
- 应用必须新增认证领域包、用户/会话数据、初始化与登录页面，以及 CSRF、限流、会话撤销和恢复测试。
- `/app/data` 现在包含不可重建的管理员凭据与设置，备份、恢复和权限要求高于纯派生媒体索引。
- 单管理员降低首版授权复杂度，但不能满足家庭成员独立账号或细粒度权限；未来多用户需要新的产品需求、数据迁移和替代 ADR。
- 内建认证不等于自动提供公网安全。公网访问仍需要 TLS、可信代理配置、依赖更新和完整发布安全门槛。
