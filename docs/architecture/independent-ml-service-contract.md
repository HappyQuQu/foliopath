# 专用 AI 服务候选合同 v1

2026-09-15；ADR-0020 / CR-2026-030；POST-MVP-5 接入阶段；FR-INT-017/019/020、
NFR-INT-007/009/010。Owner inference（薄服务），app（后续部署准入）。

保持两容器，仅私网暴露服务。此子片实现候选 AI 镜像，不启用主应用或签署发行。
固定上游 runtime digest，保留上游依赖，不重新实现 tokenizer/ONNX。

启动时按镜像内固定清单读取 `/cache`：逐路径分量使用目录 fd 与 O_NOFOLLOW，
只接受普通文件；限制条目、大小与总量，逐文件 SHA-256 验证。复制到容器内独立临时目录，
校验成功才把该快照作为上游缓存。原挂载额外内容不可进入运行时快照；推理后续不读取
宿主缓存，解决启动后宿主原路径被替换的问题。临时快照不是原媒体，没有数据库挂载。
清单当前来自已复制本地缓存，提供固定字节一致性，不冒充上游签名/供应链审核。

`GET /api/v1/identity`：协议版本、固定模型/维度、缓存清单摘要、运行时合同摘要。
运行时合同摘要覆盖上游 digest 和项目适配源文件，不是最终 OCI digest；部署须另行固定
实际镜像。响应不含路径。只在可信 Docker 部署中作为兼容证据，不是远程 attestation。
`GET /ping`：仅初始化成功后 pong。
`POST /predict`：保留已有 clip visual/textual multipart 形式，严格固定一个模型，禁止
options、额外任务、任意 URL 或模型下载。文本/图片二选一，512 码点/8 MiB，
总请求 9 MiB，最多 2 请求在途；超限拒绝，无自动重试。错误统一不包含上游异常。
上游 HTTP 层不直接发布；仅调用其内部推理和 lifespan，强制离线及快照缓存。

图片 native 预算仍由主应用 imagevips 与服务容器资源限制共同承担；此接口只接受可信
主应用的已编码图片，不作为公网图片解析服务。初始化不通过则进程失败，不能返回 ready。
主应用配置/激活、视频与人脸尚不在此子片内。

Go `NewVerified` 消费从固定镜像文件独立取得的预期身份，不把 HTTP 自报身份当作期望值。
初始化 GET 核对全部字段；每次推理成功响应还必须带匹配的 `X-FolioPath-Runtime` /
`X-FolioPath-Cache`，缺失或变化即拒绝向量。身份读取最长 30 秒、最多 4096 字节，
无代理/重定向，错误脱敏。旧 `New` 只保留原版探针兼容。
